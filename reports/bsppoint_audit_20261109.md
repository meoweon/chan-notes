# 买卖点报告审计：口径与泄漏嫌疑（2026-11-09）

审计对象：旧工作副本中的 `my_reports/bsppoint_report.html`（缠论买卖点报告，2026-11-08 生成；该文件已于 2026-11-10 作废归档为 旧工作副本的归档 `my_archive/bsppoint_report_31币_作废.html`，本文保留对原件的审计记录）。
触发：用户提出两个疑点——①回测用止盈 5×ATR，不是蓝图 v7 冻结规格（144/3.0/无止盈）；
②"true"组 IS 夏普 3.53 vs OOS 夏普 3.13 几乎零衰减，是泄漏的典型签名，且"参数+过滤"
在同批数据上选出，涉嫌双重蘸取。

## 0. 结论速览

| 疑点 | 判定 | 一句话 |
|---|---|---|
| ①回测口径≠冻结规格 | **属实** | 报告用 48bar/2ATR/TP5ATR（E001/E002 基线），确实不是蓝图 144bar/3ATR/无止盈 |
| ②零衰减=泄漏 | **不成立，基于误读** | "true"组是**完美先知标签**分组，不是"模型判真才交易"；模型为逐月 walk-forward，训练边界干净；"双重蘸取"也不成立（E001 预注册、IS 选参 OOS 只报告） |

用户直觉中**成立**的部分：那组漂亮数字（true 组 IS +748%/夏普 3.53）**没有任何可交易含义**，
全部优势来自未来标签；可交易版本（score 门控）在冻结规格下复算，样本外无稳定增量。
审计复算产物：`reports/bsppoint_freeze_audit.json`（脚本 `scripts/audit_bsppoint_freeze.py`）。

## 1. 疑点①核实：回测口径确实不是冻结规格

证据链：

- `scripts/validate_bsppoint_profit.py:38-40`：`HOLD, STOP, TP = 48, 2.0, 5.0`，
  注释明写"与 E001/E002 基线 48/2.0/5.0 一致"。
- 报告页首口径行（`make_bsppoint_report.py:484`）："基线 48bar/2ATR/5TP · 双边 13bp"。
- 蓝图 v7 冻结规格（`reports/experiment_log.md`「当前最优策略形态」）：
  144bar 时间退出 + 3×ATR 止损 + **无止盈** + frenzy 门控，A股 30m。
- `chan_notes/backtest/portfolio.py:24`：`take_profit_atr=None` 才是不止盈（冻结规格的形态）。

判定：**属实**。而且这本来就是两套策略、两个市场——报告 universe 是 31 个 USDT 永续 1h
（3462 个确认买点），蓝图是 HS300 289 股 30m。用户"数字不能互相证明"的判断正确。
报告的 §3 分组回测从未声称自己是蓝图口径；但页首没有显式声明"≠蓝图冻结规格"，
容易误导，已补警告条（见 §4）。

## 2. 疑点②核实：零衰减不是泄漏，是误读

### 2.1 "true"组不是"模型判真"，是完美先知

- `validate_bsppoint_profit.py:57-59`：`("true", (df["survive_144"] == 1).values)`——
  分组用的是 **survive_144 标签**（144 bar 内未被擦除），这个标签要 144 bar 之后才知道。
- 该脚本 docstring 第一行就声明："用「完美先知」……这是**假设验证，不是策略**：
  survive_144 是 144 bar 之后才知道的标签，结论只能说明「标签有经济含义」，
  **不能说明「当前可交易」**"。
- 报告摘要（`make_bsppoint_report.py:488`）同样写明"用完美先知标签 survive_144 …分组"。
- 报告里真正的"模型判真"是 score≥0.5（§6 阈值扫描、§11 韦恩图），
  **从未做过分组回测**——回测表里的"真（survive=1）"与模型分数无关。

### 2.2 完美先知分组的"零衰减"是设计目标，不是泄漏签名

"泄漏签名"逻辑成立的前提是：分组由**模型**做出、且模型可能训练时见过 OOS。
但这里分组由未来标签做出，IS 和 OOS 用的是同一条标签规则——
"存活→赚钱"若在时间上稳定，IS/OOS 自然接近。**这正是该实验要检验的假设本身**
（标签的经济含义是否稳定），不是管线漏洞。它什么都没证明"能交易"，
只证明了"被擦除的点后来确实不行"——一个同义反复式的、但作为假设验证合格的结论。

### 2.3 模型本身无泄漏（真正的泄漏审计点）

- `scripts/train_wf_oos.py:68-73`：逐月 walk-forward，测试月 m 的训练集为
  `t ≤ m.start_time − 28天`。
- 标签 survive_144 的成熟期 = 144 bar × 1h = **6 天** < 28 天 embargo
  → 训练样本的标签在训练截止日前已全部成熟，且事件时间严格早于测试月。
- `param_sweep_backtest.py:6-7` 注释同样声明了这套口径（v1 的三处未来函数已在 v2 修复，
  见 `docs/30_实验/E001-参数扫描样本外.md` §6 变更记录）。

### 2.4 "双重蘸取"不成立

- 48/2.0/5.0 **不是**从参数扫描里挑出来的最优，是 v1 沿用的**预设基线**。
  E001 §3.2：IS 最优是 24/5.0/5.0/p25/q80（IS 夏普 1.19），其 OOS −0.39、排第 182/480；
  `param_sweep_results.csv` 里基线（48/2.0/5.0/无门控）IS 夏普 0.63，进不了 top10。
- E001 是**预注册**实验：IS（2021-01~2025-06）选参、OOS（2025-07~2026-10）只报告，
  停止条件"跑完 480 组即停，不因结果好坏增删组合"。
- E001 的结论恰恰是**否定**了"选参数+选过滤"：H2（score 门控 +0.2 OOS）被否定，
  q80 最差 −0.65；H4（最优点是选择偏差）成立。
- 蓝图侧的同类判决更早：#18（存活过滤 +13.4% vs 基线 +46.8%）、#22（门控内过滤全负）、
  #33（tail 过滤单调恶化）——"窗口内选股"已被组合级判死四次。

### 2.5 用户直觉中成立的部分

- "all"组 OOS 夏普 −0.05 vs "true"组 +3.13 的全部落差**来自未来标签**，不可交易。
- 报告数字**不能**给蓝图 v7 背书（universe、周期、参数全不同）。
- 若有人拿"true 组 OOS 3.13"主张"模型过滤能赚钱"，那就是错读——
  模型 AUC 只有 0.667（`bsppoint_profit_validation.json`），
  离完美先知（AUC=1.0）很远，且分数越高前向收益反而越低（报告 §5/§9 已如实披露）。

## 3. 冻结规格复算（新 E1）

脚本 `scripts/audit_bsppoint_freeze.py`，与报告同一 universe（crypto_31_v1，
3462 事件），13bp 往返，10%×10 仓位。产物 `reports/bsppoint_freeze_audit.json`。
报告口径数字已复核与原 JSON 逐位一致（all/true/false 三组），管线可信。

| 组合 | 参数 | 切分 | IS 收益/夏普 | OOS 收益/夏普 |
|---|---|---|---|---|
| all | 报告 48/2.0/TP5 | 2025-07 切 | +54.2% / +0.62 | −1.9% / −0.05 |
| all | **冻结 144/3.0/无TP** | 2025-07 切 | +135.1% / +0.71 | **−14.7% / −0.29** |
| all | 冻结 | 2024-01 切 | +58.5% / +0.61 | +25.7% / +0.41 |
| true（完美先知） | 报告 | 2025-07 切 | +748.1% / +3.53 | +52.2% / +3.13 |
| true | **冻结** | 2025-07 切 | +2649.0% / +2.62 | **+56.7% / +1.53** |
| true | 冻结 | 2024-01 切 | +590.3% / +2.33 | +520.5% / +2.48 |
| false（完美先知） | 冻结 | 2025-07 切 | −91.8% / −3.03 | −52.1% / −4.39 |
| score≥月度q60（可交易） | **冻结** | 2025-07 切 | +132.7% / +0.85 | **−8.5% / −0.31** |
| score≥月度q60 | 冻结 | 2024-01 切 | +49.1% / +0.64 | +42.3% / +0.68 |

读法：

1. **标签经济含义在冻结规格下复现**：true/false 分离在两种参数、两种切分下全部成立
   （false 组全窗口 −52%~−92%）。报告的核心科学结论不依赖 48/2.0/TP5 这套参数。✔
2. **"零衰减"部分消失**：冻结规格、2025-07 切分下 true 组 IS 2.62 → OOS 1.53，
   出现了正常的 IS→OOS 衰减；原报告"3.53→3.13"的零衰减与 TP5.0 截断收益、
   压平组内差异有关。零衰减不是泄漏签名，但也不是标签的固有属性，**与参数口径耦合**。
3. **可交易 score 门控在冻结规格下无稳定增量**：q60 门控 OOS 在 2025-07 切分下为负
   （−0.31），在 2024-01 切分下 +0.68 但仅比无门控（+0.41）高 0.27，两种切分互相矛盾。
   与 E001 H2 的否定一致，**维持"score 门控不可交易"的判决**。
4. crypto 裸点本身不稳：冻结规格下 OOS 在 2024+ 窗口 +25.7%、在 2025-07+ 窗口 −14.7%，
   edge 集中在 2024-2025H1 牛市段，与蓝图（A股 frenzy 门控）的 regime 逻辑同构。

### 3.5 止盈 on/off 干净配对（2026-11-09 追加，台账 #47）

同 hold/stop、只差 take_profit（all 组，13bp，10%×10）：

| 口径 | 止盈 | IS 收益/夏普 | OOS 收益/夏普（2025-07 切） | OOS 收益/夏普（2024-01 切） |
|---|---|---|---|---|
| 48/2.0 | TP 5×ATR | +54.2% / +0.62 | −1.9% / −0.05 | −4.5% / −0.01 |
| 48/2.0 | **无** | **+133.5% / +0.98** | **+7.6% / +0.41** | **+23.0% / +0.47** |
| 144/3.0 | TP 5×ATR | +61.8% / +0.56 | −4.9% / −0.12 | +8.4% / +0.24 |
| 144/3.0 | **无** | **+135.1% / +0.71** | −14.7% / −0.29 | **+25.7% / +0.41** |

判定：**止盈不行，已禁用。**
- 48/2.0 口径下 TP5 在 IS 与 OOS、两种切分上**一致且大幅**差于无止盈（OOS 夏普差 0.46~0.48）；
  机制：收益分布为长尾（台账 #16/#20，去 top5% 即死），固定止盈=系统性截断右尾。
- 144/3.0 口径下 TP5 无一致方向（2025-07 切少亏、2024-01 切少赚），无保留理由。
- true 组（完美先知）里 TP5 夏普更高（3.07 vs 1.53）是假象：未来标签保证大涨，
  止盈只熨平路径波动——这正解释了原报告"IS 3.53 → OOS 3.13 零衰减"的部分来源，不可交易。
- 旁证：E001 网格 take_profit 8.0 vs 5.0 配对 ΔOOS −0.00（48%）——截断后多远都一样。

处置：`validate_bsppoint_profit.py` 的 TP 已改 `None` 并注释证据；
`bsppoint_profit_validation.json` 与 `bsppoint_report.html`（已归档为 `my_archive/bsppoint_report_31币_作废.html`）已按无止盈口径重算
（all 组 OOS 由 −1.9%/−0.05 变为 +7.6%/+0.41；真假分离结论不变且更干净）。

### 3.6 参数依据：48/2.0 从哪来、该不该换（2026-11-09 追加，台账 #49 / E004）

**来历**：48bar/2ATR 是 crypto v1 参数扫描网格的中心预设值
（v1 网格 hold∈{24,48,96}、stop∈{1,2,3,5}，48 与 2.0 均为中档；
`my_archive/param_sweep_report_v1_作废.html`），此后作为工程惯例沿用，
**不是任何优化或文献的产物**。

**文献**（E004 §1，P0/P1 源，2026-11-09 检索）：
- Kaminski & Lo (2014, JFM 18:234-254)：止损在动量 regime 下增值、止盈（stop-gain）
  截断右尾减值——与本仓 #47 实测同向，支持"要止损、不要止盈"，但不给数值。
- Moskowitz/Ooi/Pedersen (2012, JFE) 与 Hurst/Ooi/Pedersen (2017, JPM)：
  持有期在学术实践里是"稳健区间"（1~12 月皆有效、取惯例中心），没有最优点。
- Chandelier Exit（LeBeau，Elder 2002 推广）：3×ATR 止损是技术惯例（E2 级），
  提供 2~4×ATR 的先验区间，非学术验证。

**E004 网格复算**（hold 6 档 × stop 6 档 = 36 格，tp=None，同 universe 3462 事件，
两种 IS/OOS 切分；产物 `reports/holdstop_sweep_notp.json`）：

- **hold=48 是唯一跨切分 6/6 全正的行**（2025-07 切均值 +0.56、2024-01 切 +0.38），
  OOS MDD 也最优（−16%/−25%）；hold≥96 在 2025-07 切几乎全负——长持有纯 regime 依赖。
- 基线 48/2.0 的 OOS 排名：6/36（86 百分位）与 3/36（94 百分位），
  恰居唯一稳定平台中部。
- 两切分 IS 最优同为 48/1.5，但 OOS 排名 1/36 vs 14/36 互相矛盾
  （Spearman +0.09 / −0.28）——单格点 IS→OOS 复现是切分运气，**调参无稳定价值**。
- 结论：**平台是真的（E1），点是幸运的。维持 48/2.0 不动**；stop 维度宽档（3.0）
  两切分 ΔOOS +0.23/+0.14 方向一致但幅度不达判据，记录为现象不据此调参。
  详见 `docs/30_实验/E004-holdstop网格样本外.md`。
