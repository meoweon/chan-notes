# 131 个特征里哪些真的有效

> 样本：3,031 个「确认入场」买点（全量 17,192 事件中覆盖 12%）
> 切分：2023-06-30 前训练、之后测试（1,582 条）
> 证据文件：`reports/feature_selection.csv`（每列的 AUC、CI、稳定性、重要性、冗余标记）

## 一、分组消融：只有价格行为组有边际贡献

去掉整组特征后重训，看「大波（>2%）」标签的测试 AUC：

| 去掉的组 | AUC | 相对全量 |
|---|---:|---:|
| 全量（基线） | 0.6027 | — |
| **价格行为 pa_** | **0.5567** | **-0.046** |
| 市场 mkt_ | 0.5963 | -0.006 |
| 形态 pt_ | 0.6064 | +0.004 |
| 缠论 ch_ | 0.6079 | +0.005 |

读法：删掉 PA，模型明显变差；删掉形态或缠论，模型**反而略好**——它们在这个样本里提供的是噪声，不是信息。这不是说缠论结构没用，而是说：**在「买点已由 BSP 定义」的前提下，再用 BSP 的结构特征去预测它自己，没有增量**（类型先验已经被 one-hot 吃掉）。

## 二、多变量真正被用到的特征（11 个）

条件：permutation importance > 0.002，且逐年 AUC 方向一致率 ≥ 60%。

| 特征 | AUC(正收益) | AUC(大波) | 方向稳定 | perm_imp |
|---|---:|---:|---:|---:|
| `pa_close_pos` | 0.529 | 0.526 | 0.86 | 0.015 |
| `mkt_rsi` | 0.475 | 0.480 | 0.86 | 0.009 |
| `pa_boll_pos` | 0.483 | 0.476 | 0.71 | 0.006 |
| `pa_slope20_norm` | 0.463 | 0.455 | 0.86 | 0.005 |
| `ch_zs_pos` | 0.473 | 0.474 | 0.86 | 0.004 |
| `ch_seg_amp` | 0.489 | 0.535 | 0.71 | 0.004 |
| `ch_zs_low` | 0.468 | 0.495 | 0.71 | 0.003 |
| `pt_mm_room_up` | 0.489 | 0.563 | 0.71 | 0.003 |
| `pa_ft_body` | 0.483 | 0.476 | 0.71 | 0.003 |
| `pt_dt_neck_dist` | 0.490 | 0.488 | 0.71 | 0.003 |
| `ch_bsp2s_retrace_rate` | 0.515 | 0.515 | 0.71 | 0.002 |

注意 perm_imp 的量级：最大的 0.015，意味着打乱这一列只让 AUC 掉 1.5 个点。**这本身就是"没有强特征"的证据。**

## 三、单变量显著但效应极小（49 个）

90% bootstrap 区间不含 0.5 的有 49 列，但效应量集中在 0.51–0.55（或镜像的 0.45–0.49）。最强的几个：

| 特征 | AUC | 解读 |
|---|---:|---|
| `ch_zs_dist_high` | 0.533 | 离中枢上沿越远越好（追高不利，回踩中枢有利） |
| `pt_double_top` | 0.530 | 出现在双顶形态里反而是买点？存疑，见下 |
| `pa_close_pos` | 0.529 | 收盘靠上（阳线收在高位）概率略高 |
| `pa_vol_ratio5` | 0.525 | 温和放量略好 |
| `ch_seg_klu_cnt` | 0.524 | 线段越长，后续越容易延续 |

## 四、方向反直觉的一组（负向特征）

| 特征 | AUC(正收益) | 含义 |
|---|---:|---|
| `pa_bar_range_atr` | 0.372 | 信号 bar 振幅越大，越容易亏 |
| `pa_body_ratio` | 0.397 | 实体越大，越容易亏 |
| `pa_range_expansion` | 0.399 | 相对前一根放大越多，越差 |
| `pa_vol_on_break` | 0.404 | 突破放量，反而更差 |
| `pa_ft_strength` | 0.406 | 跟随越强，越差 |
| `pa_vol_ratio20` | 0.407 | 量比越高，越差 |

这组是本次分析最有价值的发现：**在 30 分钟上，"强信号"（大实体、放量、突破、强跟随）是反向指标**。它解释得通——买点出现在下跌笔末端，此时出现放量大阳线，往往是恐慌抛售后的反抽，而不是趋势启动。旧项目里"T1 追高失败"的现象在这里有量化证据。

但注意：这些特征对「大波」标签也是负向（0.395–0.43），说明它们不是"反向有效"，而是"两头都不灵"——高分位既不代表赚钱，也不代表不动。

## 五、冗余与死列

- **死列 3 个**（std=0）：`ch_bi_dir_streak`、`ch_seg_sure`、`ch_zs_is_one_bi`
- **近似常量**：`ch_bi_sure`（0.4% 非零）
- **冗余 46 列**：|Spearman| ≥ 0.8 被更强的一列覆盖，典型如 `pa_std_pct` 覆盖 `pa_boll_width`、`pa_atr_pct` 覆盖 `pa_range_width20`、`pa_price_vs_ma20` 覆盖 `pa_ma5_vs_ma20`
- **模型从未分裂使用 52 列**（gain=0 且打乱后预测不变）

131 → 85（去冗余）→ 约 25（去噪声）。

## 六、建议保留的核心集（25 列）

| 类别 | 列 |
|---|---|
| 位置/结构（8） | `pa_close_pos` `pa_boll_pos` `pa_range_pos20` `ch_zs_pos` `ch_zs_dist_high` `ch_price_vs_zs_mid` `pt_mm_room_up` `pa_dist_hh20` |
| 趋势/通道（4） | `pa_slope20_norm` `pa_r2_20` `pt_always_in` `mkt_ma20_slope` |
| 波动/区间（4） | `pa_atr_pct` `pa_range_width20` `ch_zs_peak_width` `ch_zs_width` |
| 量能（2） | `pa_vol_ratio5` `pa_vol_ratio20` |
| 结构长度（3） | `ch_seg_amp` `ch_seg_klu_cnt` `ch_bi_amp_prev` |
| 买卖点（4） | `ch_bsp_2` `ch_bsp_2s` `ch_bsp2s_retrace_rate` `ch_bsp_div` |

保留原则：先按消融证明「有贡献的组」排序，再在组内按冗余聚类去重；波动类特征只用于**仓位**，不用于**方向**（它们对正收益标签 AUC≈0.51，对大波标签 0.57–0.60）。

### 验证：25 列 vs 131 列

同一时间切分、同一模型参数：

| 标签 | 131 列 | 25 列 |
|---|---:|---:|
| 正收益（>0） | 0.5220 | **0.5258** |
| 大波（>2%） | 0.6059 | **0.6142** |

特征减少 81%，AUC 不降反升。这说明原 131 列里的 106 列要么是冗余，要么在训练集上制造了过拟合。

## 补充：新增 23 个 Brooks 结构特征后的复核（240 股 / 6,169 确认买点）

从 price-action-lab 移植了摆动点、环境标签、bar counting、突破强度、旗形/区间/楔形
共 23 列（详见 `feature_label_catalog.md` 第 1.5 节）。

| 指标 | 数值 |
|---|---:|
| 全特征（154 列）大波 AUC | 0.5692 |
| 去掉 brooks2（127 列）大波 AUC | 0.5735 |
| **增量** | **-0.0043** |
| 正收益 AUC | 0.4946 |

分组消融：去掉 `pa` → 0.5468（-0.022，仍是唯一大贡献）；去掉 `sw` → 0.5608（-0.008）；
去掉 `bc` → 0.5644（-0.005）；去掉 `ch` → 0.5727（+0.003）；去掉 `mkt` → 0.5783（+0.009）。

单变量最强的仍是波动类：`pa_atr_pct` 0.592、`pa_range_width20` 0.575、`pa_dist_hh20` 0.569。
新特征里最好的是 `sw_dist_h` 0.556，其余均 ≤0.53，permutation importance ≈0.001。

**结论：新增 23 列没有换来信息增量，它们与既有 pa 特征测的是同一批构念（波动、趋势强度、突破质量）。**
同时，样本从 3,031 增到 6,169 后，大波 AUC 从 0.60 回落到 0.569——此前的高值有一部分是小样本运气。

## 七、下一步可以做的

1. **删掉 3 个死列和 46 个冗余列**，用 25 列重训一次，验证 AUC 不掉——这是"特征精简不损失信息"的直接检验。
2. **补方向性特征**：相对市场强弱（个股 20 bar 收益 - 市场 20 bar 收益）、板块内排名、日内时段（10:00/14:30 的信号质量不同）、事件密度（同日同板块 BSP 数量）。
3. **换标签**：`c_pol_dir_ret` 改成对市场的超额，剔除 beta 后再看 AUC——现在的 0.53 里有多少是"市场涨所以赚"还没拆开。
4. **把波动特征用于仓位**：用 `pa_atr_pct` + `ch_zs_width` 分组，检验"高波动信号给半仓"是否改善风险调整收益，而不是拿它们做方向预测。
5. **样本扩到 300 股**：3,031 → 8,000+ 确认样本，AUC 0.57 是真是假才有定论。
