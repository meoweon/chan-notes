> 状态：**探针已跑完，判读带 = `B3_redundant_with_vol`**（跑前冻结的带子，见 §1）。
> 本档是**设计探针**的登记，不是判定实验：不宣布任何模型退役，不构成性能主张，不改任何已有产物。
> 它只回答用户的一个设计问题——「这个模型和其他标签一起使用时，岗位在哪」。

## 0. 问题从哪来

用户原话：「可以拿这个成交量模型找出流动性好的品种吗？……我现在已经有了买卖点模型和波动率模型。你觉得这个模型的标签应该设置成什么样，和其他标签一起使用比较好？」随后追问「我现在资金很小，还没有涉及到资金容量的问题」⇒ **流动性/容量这条推荐理由作废**（我在当次回答里已收回）。

收回之后剩下的唯一硬事实缺口是：本仓成交量线（[E014](E014-成交量方向基线.md)→[E017](E017-成交量回归模型.md)→[E019](E019-新信息维度_taker与资金费率.md)→[E020](E020-标签口径重定义.md)）的判据**全部是「能不能预测量」**，从来没有反向测过「预测量这件事有没有用」。grep 全库确认无先例（§7）。用户：「你试试」。

## 1. 预注册：判读带（跑前写死）

写死位置 = `exp/E021-volume-return-link/code/probe_assoc.py` 文件头（第一次运行之前已写入，可核对）。按 **B2 → B3 → B1 → B4** 顺序取第一个命中：

| 带 | 条件 | 含义 |
|---|---|---|
| B2 `direction_job` | Δr1 ≥ +5bp 且币簇 CI 不含 0，且在 `rstd24` 三分位内**三层同号** | 量的预测携带独立方向信息，值得为它设计标签 |
| B3 `redundant_with_vol` | 未命中 B2，但 Δrv1 的 CI 不含 0 | 它本质是第三个波动率模型，应与波动率线合并而非并列 |
| B1 `no_job` | Δr1 与 Δrv1 的 CI 都含 0 | 这台模型的价值只在于「用户要的就是模型本身」 |
| B4 `inconclusive` | 其余 | — |

口径约定（同样跑前定死，事后不挑）：

- 收益 = 对数收益，单位 bp。未来第 k 根沿**有效 bar 序列**（`volume>0` 且 Δt=1h）前进，与 E014/E017 标签自己的时距一致；bars 已知缺 5,042 根小时断档 ⇒ 有效序列 ≠ 日历小时，**照实披露、不做二次插值**（插值等于造数据）。
- 头牌统计量 = 逐币等权的 Δ = `mean(out | pred_up=1) − mean(out | pred_up=0)`。
- 显著性 = 69 币簇 bootstrap（10,000 次、seed 20261111），**不做行级 CI**（D048 第 3 条）。
- H=4 / H=24 窗口重叠 ⇒ 另算非重叠块版本（`pos % H == 0`）并报有效块数。
- 5bp 费用 hurdle 是**假设**（本仓未实测），只用来把 Δ 翻成人话，**不参与判读带取号**。

## 2. 数据与方法

- 输入只读：`data/bars/1h/*USDT.parquet`（69 币）。判定行 **1,686,328**（含 r1 全部 1,686,328 / 含 r4 1,686,121 / 含 r24 1,684,741）。
- **D047 零增量门**：用 E017 冻结配方（全默认参数、同 21 列、同 `random_state=0`）重训，等权 acc 复现 = **0.6727038286502596**，与 E017 发表值 `abs_dev = 0.0`（`out/assoc_summary.json` → `d047_gate.pass = true`）。用途只是拿它的逐行 `pred_up` 做关联测量，不是新性能主张。
- 结局变量：`r1/r4/r24`（未来 1/4/24 根累计对数收益）、`rv1 = |r1|`、`rv4/rv24` = 未来 4/24 根收益的 std，均 ×1e4 记作 bp。
- 同台对照：免费规则 **a5**（`vol < ma24` ⇒ 判「跌」，E014 最强零训练臂）用同一统计量、同一 bootstrap。
- OOS 段 up 基率 47.39% ⇒ 这是**双向**信号，Δ 的正负只说明分组均值，不代表多头可用。模型判"涨"的行占比 53.23%。
- 墙钟 **16.05 s**（python 3.12.16 / pandas 3.1.1 / numpy 2.5.4 / lightgbm 4.7.0）。

## 3. 结果

### 3.1 方向：没有岗位，而且是系统性反向

逐币等权 Δ（bp），69 币簇 bootstrap 95% CI：

| 结局 | 模型 `pred_up` | 免费规则 a5 |
|---|---|---|
| r1（未来 1 根） | **−1.6904** [−1.994, −1.379]，8/69 币为正 | −0.6190 [−0.946, −0.267]，21/69 |
| r4（未来 4 根） | −5.5581 [−6.885, −4.252]，11/69 | −4.0635 [−5.594, −2.549]，20/69 |
| r24（未来 24 根） | −9.5375 [−18.253, −1.170]，31/69 | −15.8272 [−25.814, −6.599]，22/69 |

三条读法：

1. **B2 需要的 +5bp 没有出现**，实测符号还相反（预测"量要涨"的那组，下一小时收益均值**更低** 1.69bp），且 CI 不含 0 ⇒ 这是可复现的反向，不是噪声。
2. 剂量反应（按 `|pred − col_lag0|` 五分位，模型越确信）：`pred_up_share` 0.0 / 0.0 / 0.66 / 1.0 / 1.0，`mean_r1` **+0.252 → +0.492 → −0.456 → −0.903 → −2.526 bp** 单调下行 ⇒ 确信度越高，方向越偏。同表 `mean_abs_r1` 86.61 → 60.65 bp 单调**下行** ⇒ 模型越确信"量涨"，未来波幅反而**越小**。
3. 每一档 a5 都不输模型 ⇒ 模型的输出在这个用途上不比一行代码强。

### 3.2 波幅：有信号，但不是它最强

| 结局 | 模型 `pred_up` | a5 |
|---|---|---|
| rv1 | **−15.1106** [−15.779, −14.434]，**0/69 币为正** | −20.9208 [−21.683, −20.150]，0/69 |
| rv4 | −10.8426 [−11.789, −9.937]，1/69 | −15.9401 [−16.737, −15.181]，0/69 |
| rv24 | −8.1952 [−9.225, −7.169]，2/69 | −7.6862 [−8.652, −6.754]，0/69 |

分层（按 `rstd24` 三分位，组内再算模型 Δrv1）：三分位边界 67.50 / 100.37 bp，Δrv1 = **−6.3301 / −12.0777 / −23.7441 bp**（三层全部 0/69 币为正）⇒ 模型在高波动区对波幅的区分度反而更大，这一条对模型**有利**，照实写。

但在**水平**层面比它和现成数字：

| 分层器 | 未来 rv1 组均值（bp） | 极差 |
|---|---|---|
| `rstd24` 三分位（t 时刻已算完的价格侧数字） | 45.67 / 65.75 / 99.35 | **53.67** |
| 模型 `pred_up` 分组 | 78.55 / 62.96 | 15.59 |
| 规则 a5 分组 | 83.79 / 62.75 | 21.04 |

比值 **3.44×**（行级 pooled）；改币内均等权口径为 46.90 vs 15.11 = **3.10×**。两种口径下结论一致：**`rstd24` 把未来波幅拉开得比模型的输出多**，而 `rstd24` 本身就是模型自己的第 21 列特征（`train.py:93-94`，收益率 24 根标准差）。

### 3.3 判读带取号

B2 未命中（Δr1 = −1.69bp，不满足 ≥ +5bp，符号还为负）；B3 条件「Δrv1 的 CI 不含 0」命中（[−15.779, −14.434]）⇒ **`B3_redundant_with_vol`**。

## 4. 偏差与披露（四条，不软化）

1. **跑后补注册。** 授权链是「你试试」（设计测量），不是阶段一预注册授权。判读带确实在第一次运行之前写进了代码头，但缺一份独立的跑前文档——本档即补齐，先后关系照实记。
2. **`rv1` 定义在跑前修正过一次**：原写「未来 1 根收益的 std」，单观测自由度为 0，构帧阶段 `RuntimeWarning`/崩溃；改为 `|r1|`（单根波幅）。修正发生在**零关联读数已产出**的窗口内，符合 D044 第 4 条；带子符号与门槛一字未动，但 B3 的对象严格说应读作「未来波幅/波动」。
3. **5bp 费用 hurdle 是假设**，本仓未做过费用/滑点实测，只用于翻译，不参与取号。
4. **作废一条读数**：本次会话早些时候我口头报过「`rstd24` 拉开 63.64bp vs 模型 25.96bp（2.45×）」，用落盘数据（`out/assoc_rows.parquet`，1,686,328 行）**复现不出来**；行级 pooled 与币内均等权两种口径分别是 3.44× 与 3.10×。**作废（2026-11-11，原因：不可复现）**，以 §3.2 为准，原文保留不删。

## 5. 连带发现：和波动率模型 / 买卖点模型的特征对比

回答「这模型是不是废了」时必须读代码，不能凭列名比。三张对照：

### 5.1 成交量模型（E017）vs 波动率模型（E008）

| | 波动率模型 E008 | 成交量模型 E017 |
|---|---|---|
| 标签 | `y_target = log_rv`＝当根 bar 自身 GK 年化 σ 取 log（`features.py:61-62,83`） | `target = log1p(next_vol)`＝下一小时总量（`train.py:139`） |
| 回看尺度 | `HORIZONS = (24,120,528)`＝1天/5天/22天（`features.py:25`） | lag 0/1/2/3/6/12/24，最长 1 天（`train.py:29-33`） |
| 当期值 | 结构上禁止：五族全 `shift(1)`（`features.py:70-74`） | `col_lag0`＝当期量，**gain 75.4%**（`train.py:83-84`） |
| 量的角色 | **只是有效性过滤器**：`df[df["volume"] > 0].drop(columns="volume")`（`features.py:43`）⇒ **19 列里一列量都没有** | 主输入：11/21 列是量 |
| 价的角色 | 全部：log_rv / ret / abs_ret / gk_var / ps_var ×3 窗口＝15 列（`features.py:65`） | 7 列：`ret_lag×6` + `rstd24`（`train.py:90-94`） |
| 类别 | `["ticker","hour","dow","month"]`（`features.py:28`） | `("coin","hour","dow")`，无 month（`train.py:34`） |
| gain 集中处 | 本档未测 | `col_lag0` 75.4% + `ewma94` 19.2% ≈ 94.6% 落在两列量上；**全部收益率 + rstd24 合计 0.074%**（[E017 §3.3](E017-成交量回归模型.md)） |

⇒ **输入层两边几乎不相交**：波动率模型看不到量，成交量模型看不到 OHLC 波幅。

### 5.2 三处「同名不同义」实证（D047 类坑的镜像）

| 名字 | E017 / E008 / BSP 里的三种含义 |
|---|---|
| `ret_lag` | E017＝单根收益率滞后 0/1/2/6/12/24；E008＝`ret_lag_24/120/528bar` **滚动均值** |
| 24 窗量均值 | E017 `ma24`＝`rolling(24).shift(1)`，**不含当期**（`train.py:86`）；BSP `pa` 的 `vma20`＝`rolling(20).mean()`，**含当期**（`indicators.py:64`） |
| `volume` | E008 里只当过滤器用完即 drop；E017 里是主输入；BSP 里是 `vol[t]/vma[t]` 的当期比值 |

跨模型拼列时这三处都会静默错位，且**没有任何一边会报错**。

### 5.3 买卖点模型（202 列）里确实有当期量，但几乎不吃重

`data/schema_v1.json` 202 列中量/额相关 **9 列**：`dy_vol_in` / `dy_vol_out` / `dy_vol_ratio` / `dy_volavg_in` / `dy_volavg_out` / `dy_volavg_ratio`（笔级量能背离，`dynamics.py:77-80`）、`pa_vol_on_break` / `pa_vol_ratio20` / `pa_vol_ratio5`（`pa.py:143-146`，`vol[t]` ÷ 含当期的 `vma[t]`）。

按 `reports/feature_selection.csv`（生成脚本 `scripts/analyze_features.py`，样本＝买点事件子集，标签 `c_pol_dir_ret>0` / `>0.02`）：

| 列 | 单列 AUC(正收益) | 95% CI | 大波 AUC | perm_imp | gain | 聚类后保留 |
|---|---|---|---|---|---|---|
| `pa_vol_ratio20` | 0.508276 | [0.495273, 0.521406] | 0.512774 | −0.000569 | 0.0 | **False**（判与 `pa_vol_ratio5` 冗余） |
| `pa_vol_ratio5` | 0.510275 | [0.497273, 0.522556] | 0.516697 | −0.001728 | 0.0 | True |
| `pa_vol_on_break` | 0.505401 | [0.493602, 0.512673] | 0.509932 | 0.0 | 0.0 | True |

三列 CI 全部跨 0.5，multivariate gain 份额 0.0（`reports/importance_stability_wf_win12.csv` 里的出现率分别是 0.265 / 0.206 / 0.162，非贡献度）。

⇒ **两个完全独立的设置**（BSP 买点事件子集 + 全小时面板）**都指向同一件事**：量的当期状态与量的前瞻预测，对「下一段往哪走」都没有可用的方向信息。这是本案最硬的一条交叉证据。

结构结论：BSP 模型读的是「**现在量是什么状态**」（当期读数），E017 预测的是「**下一小时量往哪走**」（前瞻）。两者**不冲突、不是重复劳动**；真正重复的是「当期量状态」这个信息在两套特征里各写了一份、而且写法不一致（含不含当期）。

## 6. 边界：本案证了什么，没证什么

**证了（输出层冗余）**：把这台模型的 `pred_up` 当作方向信号 → 无岗位（§3.1）；当作波幅信号 → 有信号但不如 t 时刻已算完的 `rstd24`，也不如免费的 a5（§3.2）。

**没证（三条，别当已证）**：

1. **量列喂进波动率面板**——E008 的 19 列里一列量都没有（§5.1），"量的信息已被波动率模型吃掉"在**特征层从未被测过**。E019 只证了「往量的考卷上加新信息维度值 +0.126pp」，那是另一张考卷，不可外推。
2. **量的前瞻预测喂进 BSP 事件模型**——§5.3 证的是「当期量状态」在事件模型里无量，不是「下一小时的量」无量（后者不在那 202 列里）。
3. 因果与费用：本案全程是**关联**，且 5bp hurdle 未实测。

**机制（E3，非判据）**：`col_lag0` 占 gain 75.4% ⇒ 模型主体在做的是「现在在放量 ⇒ 下一小时回落」的分级回归均值。尖峰本身在 t 时刻可观测，所以它的"预测"大部分是"读数"；读数在方向上无用（§3.1、§5.3），在波幅上被 `rstd24` 压制（§3.2）。
