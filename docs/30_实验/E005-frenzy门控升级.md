## 0. 本实验回答什么 / 不回答什么

**阶段一（本实验唯一当前判据）回答**：能否按外部参照规范的，在本仓 1h 数据上训练出一个**预测层性能可验证、产物可用**的波动率预测模型？

**阶段二（后置，不预注册判据、不排优先级）**：跨标的 / 跨周期泛化验证；以及这个模型具体怎么用——开机门控（D022 的七条判据与三个不变量原样保留，见 §9）、像原作者一样管理仓位、风险预算 / 止损宽度 / 波动预警。任一应用须另开实验、先写判据再跑。

**不回答**（阶段一）：能不能提高组合夏普、能不能替换 frenzy5、哪种用途更优。**阶段一未通过不得据结果改判据启动阶段二**；反过来阶段一阴性也不禁止后续另开实验检验用途，但须在结论里写明该先验。

**优先级声明（D030，D031 不改）**：D028 的「用途中立、应用不定死」与 D029 的「跨标的泛化优先、禁身份特征、固定留出标的组作为通过判据」**不是被推翻，而是整体后移到阶段二**。理由是：这两条把训练协议推离了原版已验证的规范（标签、模型族、宏观特征、身份特征、组合层验证），而用户明确要求先保证性能与可用性。一个实验、一份协议、一个第一优先级，避免两个实验各自冻结一套互相冲突的口径。

### 1.3 三项边界已按 D031 定案（原「跑前须拍板」项，已收敛）

D031 记录用户 2026-11-10 逐项拍板。三项由「缺口 / 待选」转为**冻结定案**，跑前不得再改、不得看结果择优：

1. **模型族缺赢家 → 定案「只训 LightGBM / XGBoost」**。实测 `.venv` 无 `torch`、无 `arch`，原版 QLIKE 最好的 **LSTM**（数值略）与 **GARCH** 训不了；用户指定「目前只训练 LightGBM / XGBoost 模型」，故**不放宽 D027、不补装依赖**。外部参照里 LightGBM 是五模型横比中表现最好的树模型，作为阶段一主学习器有依据；XGBoost 作稳健性对照。结论口径固定为「**按原版规范、在原版可达的模型子集上训练**」，**不得写成「已复刻原版五模型」**；LSTM / GARCH 后移阶段二，须另行授权且另行装依赖。
2. **共同宏观无等价物 → 定案「明确留空并登记性能缺口」**。原版使用美股宏观变量（波动率指数、长短期国债收益率与期限利差，取自公共宏观库）在 crypto 无等价物，用户明确选「留空」，故**不构造任何市场共同因子代理**：特征表不得出现 VIX 类、利率类、期限利差类、横截面 RV 中位数或全市场振幅 / 成交额等共同因子列；`protocol.json` 须把宏观策略显式记作留空而非「缺失待补」。`feature_importance.csv` 显示 VIX 系三项合计 gain 远低于 RV 滞后项，评估报告须单列**宏观特征缺位声明**：只作定性登记，**不得据此推断本仓掉了多少分、不得在结果出来后回头补造宏观特征**（不同数据、不同模型下上游 gain 不可外推）。

## 3. 标签与特征（阶段一，贴原版）

- **样本粒度沿用 D029**：`(bar_time, ticker)` 一行，长面板；1h 实例下与原版 `(date, ticker)` 面板同构，只是「一天」换成「一根 bar」。这条与贴近原版不冲突，**不作废**。
- **主标签**：该标的**下一根 bar** 的单 bar Garman-Klass 年化 σ 取 `log`（对应外部参照 next-period `log_rv_1d` 的定义）。`label_horizon_bars = 1`，标签不重叠，purge 按 bar 计且至少覆盖标签窗口；`label_estimator = garman_klass`，年化因子随 `bars_per_year` 走。
- **并列诊断（不择优、不改主标签）**：未来 24 根 bar 的 close-to-close 累计 RV、Parkinson / Rogers-Satchell 估计量。原版称 GK 效率高 7–8 倍属 **E2**，本仓未验证；crypto 24/7 无隔夜跳空使 GK 的 driftless 假设更成立，但仍不据此宣称更优。
- **GK 二选一已定案（D032，2026-11-10）**：原版一根日线 bar 含一整天的 OHLC；1h 下「单根 bar 的 GK」只有 1 小时区间，range 估计噪声显著更大。两选项为：① 严格同构的单 bar GK（默认）；② 把 24 根 1h bar 合成一个「日」OHLC 再算日 GK（统计尺度更贴原版，但退回日频标签）。**用户定案 ①**，原文：「用当周期的K线训练当周期的模型。如果要训练日K的模型，就用日K数据就好了。我们现在先用1小时数据训练它。」据此确立**周期同构原则**：将来需要日频模型时另开实验、直接用日 K 数据训练，不在 1h 实验里混入日频合成标签。② 不采纳；24 bar 累计 CC / Parkinson / RS 仍作并列诊断，**不许看结果换主标签**。单 bar GK 噪声更大写进局限（§8 风险②）。
- **特征族以原版 28 列为蓝本，扣除宏观**：窗口按协议参数从日折算到 bar —— RV / GK / Parkinson 的多尺度滞后（原版 1/5/22 日，1h 实例按 `har_windows_bars` 折算）、收益与绝对收益滞后、日历（UTC 小时 / 星期 / 月）、ticker 身份与可按原版方式编码的 categorical。**VIX / 利率 / 期限利差 / 任何共同宏观或横截面共同因子一律不进特征表**（D031 第 2 项）。qlib 158 字段清单按 D031 降为**阶段二可选消融**，不进阶段一主链路，也不在阶段一 import qlib 运行时。
- 无量纲化：`log` 目标 + HAR 尺度块；任何需要 fit 的标准化统计量只在 train 折计算，因果 rolling z-score 可借外部参照的 **形式**（只用其因果滚动算法，不引入 VIX 变量）。阶段一**不禁用**横截面标准化（该禁令属阶段二泛化对照），但不得借此引入共同宏观因子。

## 4. 模型与基线（阶段一，D031 定案）

- **候选学习器固定为两个**：**LightGBM**（主，外部参照已验证、QLIKE 在树模型里最优 为其树模型最优）与 **XGBoost**（稳健性对照）。两者同协议、同特征、同切分、同 seed 集横比，结论并列、不择优。每组超参在 IS 一次早停确定并写入产物，OOS 不调；`seed_count ≥ 5`，报告种子间标准差与排序稳定性。
- **基线（不是候选模型）**：persistence / naive（纯 numpy）、**HAR-RV 带 ticker 固定效应的 pooled OLS**。HAR 不放水——不得改成 D029 稿的纯 pooled，否则「双指标同时优于基线」变成自证。OLS 用 `numpy` / `scipy` 现成最小二乘配合显式虚拟变量实现，**不装 statsmodels**。

## 5. 切分、评估与判据（阶段一，唯一当前判据）

- **绝对日期写死**，不从数据末尾相对推导：IS `2020-01-01 ~ 2023-12-31`（训练、早停、冻结超参），OOS `2024-01-01 ~ 2026-10-31`（只在最终判定用一次）。

### 5.3 可用性判据（只验「能用」，不验「哪种用途更优」）

### 10.1 执行结果与判定（2026-11-10，E1）

全量 walk-forward 于 11:52 完成：34 折 × 2 候选 × 5 seed = **340/340 拟合**，4 模型 OOS 有效交集 **1,235,809 行**（训练宇宙内 1,111,729 行）。判定口径为 §5.1 三条，产物 `exp/E005-vol-forecast/out/evaluation_report.json`（`protocol.json` sha256 `03b1e686…390947b` 跑前跑后一致，协议未改）。

**结论：阶段一判阴性**（`overall_pass = false`），失败在判据①，②③全过。

判据①「QLIKE 与 log 空间 MSE 同时优于 persistence 与带固定效应的 HAR-RV」，45 币逐币等权口径：

| 模型 | QLIKE | MSE(log) |
|---|---|---|
| lightgbm | **0.8820** | 1.4057 |
| xgboost | 1.0385 | 2.4920 |
| har（基线） | 1.0320 | **0.2264** |
| naive / persistence（基线） | 2.12e11 | **0.2612** |

两候选 QLIKE 优于两基线，但 MSE 差 6–11 倍 → 「同时」不成立，判据①不过。R² vs HAR（训练宇宙）：lightgbm −5.24、xgboost −10.04、naive −0.15。

判据②：5 seed 两两 Spearman 均值 0.9979（lightgbm）/ 0.9984（xgboost），阈值 0.95 通过；首折 2024-01 逐位复算 `bitwise_identical = true`（两模型、34,974 行、`max_abs_diff = 0.0`，70.2s）。判据③：防前视 8 项断言全绿、协议跑前冻结。

**阴性根因（定位到机制，不是"模型无信息"）**：标签地板值支配了 MSE 项。`features.py:24,54` 与协议 `label.floor` 对**年化** σ 取 `clip(lower=1e-8)`，故零区间 bar（`high==low` 且 `close==open`）的 `y_true` 恒为 `ln(1e-8) = −18.420681`。OOS 内此类行 **29,085 行 = 2.354%**，却贡献了候选 MSE 的 **86.7%（lightgbm 1.117/1.288）与 92.4%（xgboost 2.094/2.265）**，而两基线只从这些行损失 0.0222 / 0.0144——基线能把地板值原样抄近来，树模型只能给条件均值。naive 的 QLIKE = 2.1e11 是同一机制的反向表现：前一根是零区间 bar 时预测落在地板、真值正常，`exp(2d)` 项到 1e15 量级。

剔除 29,085 行地板值后（n = 1,206,724，仅诊断、不改判定）：MSE lightgbm **0.1748** / xgboost **0.1752** vs har 0.2076 / naive 0.2527，QLIKE **0.7575 / 0.7585** vs har 1.0564 —— 两候选在双指标上同时优于两基线。留出标的组口径（§5.2 报告项）同样双指标同时优于：lightgbm 0.7767 / 0.1836、xgboost 0.8079 / 0.1841 vs har 1.0903 / 0.2132。

地板值集中在三个数据退化币，是**数据层事实**（E1，逐币 OOS 统计）：FTMUSDT 15,903/24,816 根 = **64.1%**、MKRUSDT 10,024 = **40.4%**、TONUSDT 3,111/23,364 = **13.3%**，其余 47 币各仅 1 根（2026-11-10 更正：原文写「66 币」，系把目录里的 69 个文件当成宇宙；冻结宇宙 50 币内为 47 币，且这 47 根全部落在同一小时 2024-10-28 20:00，见 §12 与 [E008 §1 事实 F4](E008-死价bar剔除后重训.md)）。这正是 §8 风险②「1h 单 bar range 噪声显著大于日线」的具体化，也与上游日频几乎不出现零区间 bar 的前提不同。
