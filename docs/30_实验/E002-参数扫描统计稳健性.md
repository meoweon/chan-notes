# E002 参数扫描的统计稳健性检验（Layer 1）

- 日期：2026-11-08
- 状态：预注册
- 关联仓库：本仓
- 前置实验：E001（480 组样本内外分离）
- 代码：`scripts/analyze_sweep_significance.py`

## 1. 预注册（运行前填）

### 问题

E001 跑出的 480 组里，IS 与 OOS 的夏普差异到底是「可迁移的参数边际」，还是「多重比较 + 小样本下的噪声」？
本实验不新增参数、不改策略，只对既有 480 组结果做统计稳健性检验。

### 假设（一次性报告，跑完不改判据）

- **H1 可迁移性**：480 组上 `sharpe_is` 与 `sharpe_oos` 的 Spearman 秩相关 ρ > 0。
  判据：ρ > 0 且置换检验 p < 0.05（把 OOS 夏普在组间打乱 2000 次）。
- **H2 基线边际**：基线组合（hold=48 / stop=2 / tp=5 / 无门控）的 OOS 夏普显著非零。
  判据：按月分块自举（B=2000）的 95% CI 不包含 0。
- **H3 门控价值**：IS 最优组合（hold=24 / stop=5 / tp=5 / frenzy=p25 / score=q80）的真实 OOS 夏普，
  高于「等量事件随机抽样」置换零分布的 95 分位。
  判据：真实值 ≥ 零分布 P95。
- **H4 极值稳定性**：480 组里 OOS 夏普最高的组合，其 OOS 夏普的块自举 95% CI 不跨 0。
  判据：CI 下界 > 0。

预期（E1 观察到的先验）：H1、H2、H3、H4 大概率都不成立，即「参数边际不可迁移、极值是选择偏差」。

### 数据与切分

与 E001 完全一致：2264 个确认买点事件，21 个 USDT 永续 1h；
IS = 2021-01-01 ~ 2025-06-30，OOS = 2025-07-01 ~ 2026-10-31；往返成本 13bp。
输入产物：`reports/param_sweep_results.csv`（480 行）。
需要收益序列的假设（H2/H3/H4）用 `param_sweep_backtest.py` 的 `run_combo(..., return_equity=True)` 现场重算，
复用同一 `build_context()`（数据、分位阈值、模型分数都不变）。

### 方法

- **块自举**：以自然月为块重抽（保留事件聚簇与自相关），B=2000；
  每组算 OOS 月度收益序列的年化夏普 = mean/std × √12，与累计收益 = ∏(1+r)−1；
  报 2.5/97.5 分位。
- **置换检验（H3）**：取该组合门控后的事件数 k，从 2264 个事件中无放回随机抽 k 个，
  用相同出场参数重跑回测，得 OOS 夏普；重复 B 次构造零分布。
- **秩相关（H1）**：Spearman + 置换 p 值。

### 停止条件

四项假设各跑一次、各报一个数字；不因结果不理想而调整方法、窗口或成本。

## 2. 结果

- 状态：阴性（跑完 2026-11-08）
- 代码：[analyze_sweep_significance.py](../../scripts/analyze_sweep_significance.py)
- 产物：`reports/perm_log.txt`（C 部分零分布日志）

### 2.1 假设判定

| 假设 | 结果 | 判据落地 |
|---|---|---|
| H1 可迁移性（IS↔OOS 秩相关 >0） | **弱支持**（ρ=+0.229，置换 p<0.001，但量级太小，选不出能用的组合） | 去 stop 主效应 ρ=+0.155、去 hold 主效应 ρ=+0.289；收益的秩相关 −0.025 |
| H2 基线 OOS 边际（CI 不含 0） | **拒绝** | 基线月频 OOS 夏普 +0.03，95% CI [−2.09, +1.95] 跨 0 |
| H3 门控优于等量随机抽样 | **拒绝（强）** | 真实 −0.74 位于零分布第 90.2% 分位，即比约 90% 的随机抽样更差 |
| H4 极值稳定（OOS 最优 CI 不含 0） | **拒绝** | OOS 最优 +0.84，CI [−1.15, +2.50] 跨 0 |

### 2.2 关键数字

- 网格整体：OOS 夏普为正约占 1/4，中位 −0.72，最大 +1.36，最小 −2.06。
- 秩相关（n=480）：`Spearman(sharpe_is, sharpe_oos) = +0.229`（置换 p<0.001）；
  `Spearman(ret_is, ret_oos) = −0.025`。分层看，stop=5.0 组内 ρ=−0.07、frenzy=p25 组内 ρ=−0.22，
  其余多数层内为正（0.07~0.37），说明弱相关不是单一粗维度伪造的，但也不足以选优。
- 块自举（OOS 窗口，按月分块，B=2000，月频年化夏普 = mean/std×√12，共 15 个月）：
  - 基线 48/2/5：夏普 +0.03，CI [−2.09, +1.95]；收益 −0.1%，CI [−15.6%, +18.5%]
  - IS 最优 24/5/5/p25/q80：夏普 −0.74，CI [−4.66, +0.90]；收益 −2.0%
  - OOS 最优 24/5/8/p25/q40：夏普 +0.84，CI [−1.15, +2.50]；收益 +5.5%，CI [−4.7%, +18.9%]
- 置换检验（C，500 次）：IS 最优组合门控后 385 个事件，真实 OOS 夏普 −0.74；
  等量随机抽样的零分布中位 +0.25、P95 +1.44、最大 +3.05。真实值低于零分布中位数，
  即这套门控在样本外不仅没有增量，反而显著劣于随机选 385 个事件。

### 2.3 结论

参数组合在 480 组网格上**不存在可用的样本外边际**：

1. 基线本身的 OOS 夏普 CI 跨 0，无法证明这套入场信号在样本外有风险调整后收益；
2. 即便按 IS 夏普排名挑选，选出来的组合 OOS 夏普仍为负（−0.74），且门控劣于随机抽样；
3. OOS 表现最好的组合，其 CI 也跨 0，属于噪声；
4. 唯一的非零信号是 IS 夏普对 OOS 夏普的弱秩相关（ρ≈0.23），量级太小、且主要落在夏普空间
   而非收益空间，无法据此选参。

与 E001 的结论一致，并把它推进了一步：E001 只说明"IS 最优在 OOS 表现差"，
本实验证明"任何按 IS 选出来的组合，其 OOS 表现都落在噪声带内，门控甚至为负"。

### 2.4 口径说明

本实验月频夏普（mean/std×√12）与 `param_sweep_results.csv` 里的日频年化夏普口径不同，
故同一组合的绝对值有差异（如基线月频 +0.03 vs 日频 +0.19）；结论（CI 跨 0）对两种口径都成立。
C 部分每轮都要重跑整条时间线，500 次约 10 分钟。

读法：

1. IS 最优在样本内胜率（57.4%）、盈亏比（1.21）、每笔期望（+1.0%）都优于基线，换到 OOS 后
   胜率掉到 34.5%、每笔期望转负（−0.3%），区间跨 0；
2. 基线的胜率只有约 36%，靠 2.0 的盈亏比把每笔期望撑到 +0.2%，扣成本后贴近 0；
3. 频率差异很大（基线 331~356 笔/年，IS 最优 41~69 笔/年）。高盈亏比组合常以低胜率、
   低频率换取，单看任一指标都会误判；
4. 恢复天数只能当参考：基线与 IS 最优 OOS 的最大回撤在窗口内都没有回到前高，显示“未恢复”；
5. 若改按“每笔期望”选参，样本内最优是 hold=96 / stop=5.0 / tp=8.0 / frenzy=p90 / 无，
   IS 每笔 +5.5%，OOS 每笔 −4.7%，在 480 组里排第 480（最差）——换主指标选优同样过拟合。

结论不变：**不存在可迁移的样本外边际**。

### 2.6 选参流程净值（事后不可选）

图 1 的旧画法（按夏普/收益各挑一条事后最优）在 D016 口径下不成立。改为模拟**可落地的流程**：
每年 1 月 1 日只用此前数据、按“每笔期望”选出参数，当年照用，下一年重选；与“什么都不选”的
固定基线、以及“给足事后视角”的作弊上限对比。

规则：历史成交 ≥ 30 笔，且历史频率 ≥ 100 笔/年（不设频率下限会选到几乎不交易的组合，见下）。
脚本 `scripts/rolling_selection.py`，产物 `reports/rolling_selection.json`、
`rolling_selection.png`（图 1）、`rolling_metrics.png`（图 2）。

读法：

1. 滚动选参**没有跑赢基线**（1.118 vs 1.134）；给足事后视角也只多 2.4 个点（1.158），
   说明“按每笔期望挑参数”本身不提供可用信息，不是“没选准”的问题；
2. 去掉频率下限后反而更差（0.936）：它会一路选到 p90 这类一年成交个位数的组合——
   每笔期望是**按笔平均**，交易越少越容易被少数几笔拉高，必须配频率下限才不是钻空子；
3. 图 2 显示四项交易型指标逐年跳动（滚动选参 2023 年胜率 28.6%、2024 年 58.8%），
   任何单年结论都不可靠；
4. 边界：2026 年的选参用到 2025 下半年数据，那一段已不是 E001 划定的样本外；
   真正没被本研究看过的数据只有 2025-07 之后。
