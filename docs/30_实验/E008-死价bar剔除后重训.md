## 1. 预注册（运行前填）

### 问题

把 `volume == 0` 的死价 bar 整根剔除后重新训练，LightGBM / XGBoost 能否在 **QLIKE 与 log 空间 MSE 两个指标上同时**优于 persistence 与带 ticker 固定效应的 HAR-RV？

### 假设

- **H1**：E005 判阴性由数据层伪影造成。`volume == 0` 的 bar 不含价格发现信息（四价相同、连续整段、无成交），GK 估计量在其上未定义，`clip(σ, 1e-8)` 把一个"未观测"硬变成"零波动"；把它们排除在样本之外（训练与评分同时排除）后，判据①成立。
- **H0（本实验要能接受的结果）**：剔除后判据①仍不过 → 地板值只是遮住了真实差距，模型对下一根 bar 的 GK 波动确无增量信息，E005 的阴性结论升级为"数据层已排除"。
- **不依赖归因**：这些零量行由交易所聚合产生还是由本仓抓取环节补齐，现有证据分辨不了，本实验也不需要分辨——判据只用"该 bar 是否含价格发现信息"这一可机械判定的条件。唯一的例外是 F4（全站同一小时零成交），BTC 在该小时真的没有一笔成交不可信，故至少该小时属接口/抓取缺口。留一个可证伪的后续检查：与 Binance vision 官方月度 zip 对拍同一根 bar 的 `volume` 与成交笔数字段。

### 已知性声明（诚实项，先于结果写死）

E005 §10.1 已在**评分侧**剔除过这 29,085 行，那一版诊断结果已知为"双指标同时优于基线"。本实验真正未测的是**训练侧一并剔除并重训 340 个模型**（模型不再为地板值分配容量）与**剔除后滚动窗口按有效 bar 压缩**这两件事。因此：

1. 本实验的阳性只等于"机制成立、效应方向在已见数据上得到重训确证"，**不得写成性能结论**，也不得写成独立确证；
2. 判据、切分、参数、指标一律照抄 E005，不因看到中间结果而调整；
3. 独立确证只能来自新的时间段（§7 阶段 B）。

### 判据（跑前冻结，只看一次）

与 [E005 §5.1](E005-frenzy门控升级.md) 同构，三条全过才判阳性：

| 编号 | 判据 | 阈值 | 口径 |
|---|---|---|---|
| C1 | 双指标同时优于双基线 | lightgbm **或** xgboost 的 QLIKE 与 MSE(log) 四项全部同时 < har 且 < naive | 45 训练币**逐标的损失等权平均**（禁用行级平均），与 E005 完全同一函数 |
| C2 | 种子稳定 + 逐位复算 | 5 seed 两两 Spearman 均值 ≥ **0.95**；首折 2024-01 全 seed 重训后 `bitwise_identical = true` | 同 E005 |
| C3 | 防前视 + 协议冻结 | `test_features.py` 断言全绿；`protocol.json` 跑前跑后 sha256 一致 | 同 E005 |

硬自检（不是判据，失败即判"不可判定"并先修管线，不得出结论）：

- **S1**：`features.py` 在构建后断言 `y_target == ln(1e-8)` 的行数为 **0**。2026-11-10 预实测：`volume>0` 的 2,313,120 行中 GK var ≤ 0 的行数为 0，故此断言可成立；不成立说明过滤规则没生效。
- **S2**：报告 OOS 有效交集行数，并与 E005 §10.1 的 1,206,724（剔除后行数）对齐；差异 > 1% 须逐币解释后才能判定。

停止条件：候选训练总机时 ≤ **1.5 h**（34 折 × 2 模型 × 5 seed = 340 拟合，E005 实测 1h20）；**只跑一次**；C1 不过即停，不得改过滤阈值（例如换成 `volume < 某值`）、不得增删臂、不得换指标、不得回头重新调参。

### 数据

- 来源：`data/bars/1h/<TICKER>USDT.parquet`，字段 `time/open/high/low/close/volume/amount`；宇宙为 E005 冻结的 **50 个 USDT**（`protocol.json` `data.universe_frozen`），不用当下成分回填历史。
- **有效性规则（本实验唯一改动）**：`volume > 0` 才进样本。剔除后该 bar 不进 `rolling` 窗口、不产生标签、不进训练与评分；序列按剩余 bar 压缩，`shift(1)` 指"上一根有效 bar"。
- 区间：IS `2020-01-01 ~ 2023-12-31`，OOS `2024-01-01 ~ 2026-10-31`，与 E005 逐日一致。2026-11-01 以后新抓的 bar **不进任何折**（末折测试窗止于 2026-11-01）。
- 缺失处理：不为死价 bar 造值，不做前向填充；`amount` 本实验不使用（D035 的回填与本题无关）。

行数字典闭合（E1）：E005 面板 2,333,181 行（含窗内死量行 29,085 = F1 的 29,661 − F6 新增 576）；E008 面板 = 2,333,181 − 29,085 + 9,024（11 月有效 47 币 × 192）= **2,313,120**，与 F2 实测一致。11 月那 9,024 行不进任何折：末折月份为 2026-10，`test` 掩码上界 `hi = 2026-11-01`（`code/train.py:57`），`train` 掩码上界是各折起点减 purge/embargo，恒 ≤ 2026-09 → 新段既不在训练也不在评分里，E008 与 E005 仍是**只差有效性规则**的单变量对照。

结论前提：F3/F4 说明这些行**不含价格发现信息**——连续整段四价相同、成交量恒 0、bar 一根不缺；至于是交易所聚合层就这样返回还是抓取环节补齐，本实验不作归因判定（见 §1「不依赖归因」）。E005 的 `clip(σ, 1e-8)` 把它们变成 `ln(1e-8) = −18.420681` 的标签，单行 MSE 可达数百，故 2.354% 的行贡献了候选 MSE 的 86.7%/92.4%。

### 切分

- 34 个自然月 purged walk-forward 折，`purge_bars = 24`、`embargo_bars = 24`，标准化只在训练窗，末 6 个日历月连续验证块用于早停——**全部沿用 E005 冻结值，不因剔除而移动日期边界**（剔除只让每折行数变少）。
- 超参：直接用 E005 IS 一次评定后冻结的 `tuned_params.json`（LGBM `num_leaves=31/min_data_in_leaf=500`，XGB `max_depth=5/min_child_weight=100`），**本实验不重新调参**。理由：单变量设计，只动数据过滤；重新调参会同时改两个变量，无法归因。
- 留出标的组 5 币（ADA/COMP/INJ/PYTH/WLD）永不进训练，只作报告项，判据口径不含它们——与 E005 一致。

### 成本与成交

不适用。本实验停在预测层，不下单、不接回测、不改 `chan_quant/gates/`。§5.3 的 vol-target 诊断仍按 E005 口径报告（1bp / 5bp 为上游美股诊断口径，12bp 为 crypto taker 往返），**只作量纲自洽与换手可接受性的诊断，不是判据**。

### 样本量与检验

- 全历史有效 2,313,120 行；OOS 有效交集预计与 E005 剔除后 1,206,724 行同量级（S2 核对）。
- 主判定是点比较（四指标 × 两候选 vs 两基线），不做"显著性择优"；另报逐币 MSE 差的币簇 bootstrap（1,000 次重抽、seed 固定）95% CI 作**报告项**，CI 不参与判定。
- 无多重比较校正需求：判据只有一条，臂不增。

### 预期反例

- C1 不过 → H1 被否，地板值不是可消除的根因；此时 E005 的阴性应重述为"在数据缺陷已排除的条件下仍无增量信息"，并把下一步指向标签本身（E005 §8 风险②：1h 单 bar range 噪声）。
- C1 过但 C2 的 Spearman < 0.95 → 剔除后样本变小使种子不稳定，判"不可判定"，不得宣称阳性。
- C1 过但**逐币方向不一致**（多数币 MSE 仍差于 HAR）→ 判"聚合口径掩盖异质性"，登记为不可推广。
- S1 失败（过滤后仍有地板行）→ 过滤规则实现有误，本实验作废重做，不判。

## 4. 结论

1. **按冻结判据，E008 判阳性**（`overall_pass = true`，两候选各自通过 C1，C2/C3 全过）。停止条件已遵守：未改过滤阈值、未增删臂、未换指标、未回头重新调参。
2. **地板值是 E005 MSE 崩塌的根因——机制确证，且是很硬的确证**：候选 MSE 降 8.0 / 14.2 倍，R² vs HAR 由 −5.24 / −10.04 转为 +0.158 / +0.158，S2 行数与 E005 剔除地板值后的口径逐行相等（差 0）。E005 的阴性现在可以重述为：**在数据缺陷排除后，模型族在 log-MSE 与相对 HAR 的解释力上确有增量信息**。
3. **"候选优于 persistence"这句话不成立为稳健结论**。C1 通过靠的是 QLIKE 点估计赢 0.42%（lightgbm）/ 0.58%（xgboost），但币簇 bootstrap 的 95% CI 跨 0、45 币中 21 币反而更差；换到行级口径两位候选都输给 naive（0.75221 / 0.75409 vs 0.74887），换到留出 5 币口径输 7.9% / 11.1% 且 xgboost 的 CI 整段在更差一侧。**判定过 ≠ 有增量**，这一条按预注册 §预期反例的精神登记为结论限定，不回改判据。
4. **性质限定**：本实验与 E005 判阴性用的是同一段已被看过的 OOS（2024-01~2026-10），属**已见数据复判**，只确证机制，**不得声称独立业绩**（协议 `declarations.oos_usage` 已写明）。独立确证须走 §6 阶段 B。
5. **对下一步的指向**：真正需要解决的是判据形态而非数据——C1 用点比较，在 persistence 这道几乎并列的基线前会给出"通过"这种误导性字样。若要把"ML 是否强于 persistence"变成可判定的问题，需要新的决策与**新时间段上的新判定**（建议主口径带币簇 CI 或逐币胜率，且 CI 跨 0 时判"不可分辨"而非"通过"），本实验内不实现、不回改。
6. **口径副作用**：`volume > 0` 剔除后 `naive` 的 QLIKE 从 2.12e11 变成 0.75112，说明 E005 报告里"两候选 QLIKE 优于双基线"的结论**主要是那 50 行伪影造成的假赢**。任何沿用 E005 QLIKE 数字的对比都要带这条限定。
