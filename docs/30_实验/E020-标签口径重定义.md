## 1. 预注册（运行前填）

### 问题

E017 实测：同一张 OOS 考卷上，同源加列已无量（收益率组总 gain 0.074%）；E019 实测：换成真正不同源的 taker flow + 资金费率也只值 **+0.126pp**（门槛 +1.0pp 的 1/8）。**「同一张考卷再加特征」这条路穷尽。**

本实验问剩下的第二条路：**把「下一小时成交量方向」这个标签的参照物或时距换掉，能不能得到一个既非平凡（最强因果零训练规则过不了 70%）、又能让模型诚实达到 70% 的口径？**

这个问题必须拆成两问，且**第一问先于第二问**：

1. **口径本身是否非平凡？** 若换个参照物就让一条查表规则拿到 70%+，那 70% 是口径送的，不是模型挣的——这种口径直接淘汰，不训模型。
2. **在活下来的口径上，模型比该口径的因果零训练天花板高多少？** 这才是模型的成绩。

### 假设

- **H1（阶段二跑前预期，E3，可证伪）**：L4 口径下模型 OOS 逐币等权 acc 落在 **0.66~0.74**，对因果零训练天花板 0.603292 的 Δ 为 **+3~+8pp**；**达到 0.70 的概率约 40%**。理由（全部来自阶段一实测，不是直觉）：目标噪声降 22%（`log1p` 标准差 0.830829 → 0.651444），但 persistence 的**相对**难度反而升（MAE/目标标准差 0.501 → 0.774）——两个方向抵消，**不能假定「平滑 = 更容易」**。
- **H0（零假设，必须能接受）**：L4 的 Δ ≤ 0，或 acc < 0.70 ⇒ 口径重定义这条路关闭，70% 只剩「数据质量」（E008 线）一条路可争取。照实写阴性，不补救（D042 第 1 条）。
- **阶段一的跑前预期（已对账，见 §3.4）**：原以为「换参照物」是中性操作，实测发现它系统性地**把考卷变简单**——四个重定义里三个直接平凡。这条预期被证伪，照实登记。

### 判据

- **C1 非平凡性门（阶段一已判，先于任何模型训练）**：某口径下**最强因果零训练臂**的 OOS 逐币等权 acc 与 pooled acc **均 < 0.700** ⇒ 该口径可进入阶段二；任一 ≥ 0.700 ⇒ 判 `trivial_70`，**该口径不训模型**。阈值 0.700 与判定形式逐字继承 E014 的 `TRIVIAL_THR` / `trivial_70` 逻辑，不新造。
  - 实测：**L1 / L2 / L3 全部 `trivial_70`（且 69/69 币都 ≥0.70）→ 淘汰**；**L4 `nontrivial_70`（0.603292 / 0.603195，0/69 币 ≥0.70）→ 唯一进入阶段二的口径**；L0 是锚（0.623817，`nontrivial_70`）。
  - **主口径由 C1 唯一选出，不是由模型成绩选出**——这是防「口径挑选」的硬纪律：阶段二只跑 L4，跑完不得回头挑 L1/L2/L3 报阳性。
- **C2 主判定（阶段二跑前写死）**：`m1_L4 − z_ref_persist` 的 OOS 方向 accuracy（逐币等权，69 币）**Δacc > +0.020** 且 pooled 同向 且 balanced accuracy 更高 ⇒ 判 `caliber_learnable`；Δacc ≤ 0 ⇒ 判 `negative_caliber`；0 < Δacc ≤ 0.020 ⇒ 判 `marginal`。
  - 门槛 +2.0pp 逐字继承 E017 的 `DELTA_GATE`（对手从零训练基线换成「该口径最强因果零训练臂」，性质与 E017 相同，故不放宽）。
  - 披露口径与判定口径**同一表达式**（D044 第 2 条）：分子 = 逐币等权 acc 差，分母 = 69 币，判定行集固定 **1,684,522** 行。
  - 对手 `z_ref_persist` 的冻结值 = **0.6032921454206961**（等权）/ 0.6031948529018915（pooled）/ 0.5975582542477516（bacc），由 `out/probe/probe_summary.json` 落盘，**不从对话抄**。

## 2. 实现

### 2.1 阶段一（已跑）

`code/probe_calibers.py`：只读 bars、**不训任何模型**，两趟遍历 69 币（第一趟收 IS 统计以复刻 E014 的 pooled 回退，第二趟算判定行与臂）。产物 8 件落 `out/probe/`：`probe_summary.json` / `zero_train_by_coin.csv` / `zero_train_summary.csv` / `caliber_rows_by_coin.csv` / `reduced_rowset.csv` / `forward_mean_check.csv` / `profile_cells.csv` / `run_metadata.json`。墙钟 **7.94 秒**。

**一处前视 bug 的自查与修正（本实验最重要的实现事实）**：

- 第一版探针对所有口径都用 `y.shift(1)`（上一行标签）作 inertia 臂。**这对 L2/L4 是前视**：L4 在 pair (t−1, t) 上的标签用到 **t+26** 根 bar，在决策时刻 t 根本还没结算。
- 污染读数：L4 `z_inertia` = **0.9593580238868924**、L2 `z_inertia` = 0.7155411316382394，L4 因此被误判 `trivial_70`。
- 修正：给每个口径显式落一列 `label_info_end`（L0/L1/L3 = `next_t`；L2/L4 = t+27 根 bar 的时间戳），inertia 一律取「**信息窗已闭合的最近标签**」（`searchsorted(ends, t, side='right') - 1`），并硬断言 `info_end <= t`。L0/L1/L3 下该构造与 `y.shift(1)` **逐位相同**（已断言），故 E014 的 a3/a4 仍逐位复现。
- 修正后 L4 的因果 inertia = **0.433745**（低于随机，反持续），最强因果臂换成 `z_ref_persist` = **0.603292**，判定从 `trivial_70` **翻成 `nontrivial_70`**。**一个前视臂差点把唯一可用的口径误杀。**
- 污染版按「作废不删」整目录存档：`out/probe_archive_lookahead_inertia/`，**其 L2/L4 的 inertia / contrarian 读数一律不得引用**。
- 同一 bug 类还波及 IS 拟合：L2/L4 的 IS 末端标签窗伸进 OOS，故 `fit_is_stats` 的输入改为 `label_info_end < IS_END` 的子集（L0/L1/L3 下与 E014 逐字等价）。阶段二的训练边界同此（C5③）。

### 3.2 机制：为什么换口径会把考卷变简单

**L0 的标签是反持续的**（lag-1 自相关 **−0.178857**，inertia acc 0.412209 < 0.5）——这正是它难的原因：上一小时涨不涨，对下一小时涨不涨几乎没有正信息。

**任何把比较的一侧平滑化的重定义，都会把标签变成持续的**，而持续标签的最强预测子就是它自己：

- L1（参照物换成 24h 均量）：自相关翻正到 +0.409，`vol_t > ma24_t` 一条规则就 0.7287；
- L3（参照物换成小时剖面中位数）：自相关 +0.548，「当前小时在不在剖面之上」直接 0.8284；
- L2（被预测量换成 27h 均量、参照物仍是噪声大的当前小时）：自相关 +0.395，均值回归规则 0.7969；
- L4（**两侧都平滑**）：自相关飙到 **+0.918559**，但**这份持续性在因果上不可用**——要用上一行标签就得等 27 小时，等到时窗口已换。故因果 inertia 只有 0.433745（仍是反持续），因果天花板回落到 0.603292。

**结论：70% 是口径的性质，不是模型的性质。** L4 之所以是唯一活下来的口径，恰恰因为它**两侧同时平滑**，把「标签自相关」与「因果可用信息」解耦了：目标噪声降 22%，而反持续结构（难题的来源）保留。

## 4. 结论

### 4.1 阶段一（已判）

1. **「标签口径重定义」不能用来诚实地达到 70%——除非换到一个新的问题上。** 四个自然重定义里，L1/L2/L3 让一条零训练规则在 **69/69 币**上都过 70%（0.7287 / 0.7969 / 0.8284），70% 在这些口径下失去判别力，**依 C1 淘汰，不训模型**。
2. **唯一活下来的口径是 L4（未来 27 小时均量 vs 过去 27 小时均量）**：因果零训练天花板 0.603292（0/69 币 ≥0.70）、基率 0.479871（接近平衡）、目标噪声比 L0 低 22%、反持续结构保留。它是一个**良定义的新问题**，值得训一次模型。
3. **但必须先把话说清楚**：L4 上就算拿到 0.70+，也**不等于**用户原目标（L0 口径「下一小时成交量方向」>70%）达成。L0 上模型仍是 **0.672704**，距 70% 差 2.73pp，而 E017/E019 已证明同一考卷加特征无量。**换口径是换问题，不是把模型变强。**
4. 方法论产出：一个前视臂（`y.shift(1)` 用在标签窗跨期的口径上）差点把唯一可用的口径误杀，读数 0.9594 → 0.6033、判定 trivial → nontrivial。立 D048。

### 4.2 阶段二（已判）

1. **L4 是一张「模型能学到东西」的考卷：C2 判 `caliber_learnable`。** 同一批 21 列特征、同一个冻结学习器，模型 0.690249 对该口径最强因果零训练臂 0.603292 的 **Δacc = +8.696pp**（门槛 +2.0pp），pooled 同向 +8.728pp、bacc 更高 +9.567pp，**67/69 币为正**，双层 bootstrap CI95 [7.894pp, 9.451pp] 不含 0、10,000 次重抽样无一次跌破门槛。阶段一淘汰 L1/L2/L3 之后，L4 没有被淘汰——它没有被白送，是被模型挣的。
2. **但「换口径能不能诚实地到 70%」的实测答案是：不能。** L4 上 eq **0.690249** / pooled **0.690475**，两条都差约 1pp 没到 0.700；**bootstrap 上界 0.697481 仍 < 0.700**，不是抽样噪声能盖过去的差距。逐年只有 2025（0.702754）单年过线，全期没过。⇒ 依预注册 §1 的预期反例，口径重定义这条路**判到「可学但未达标」为止关闭**。
3. **对用户原目标是零推进，必须写明。** 用户要的是 L0 口径「下一小时成交量方向」>70%，L0 上模型仍是 **0.672704**（本次 `a0_anchor_L0` 用 E017 自己的管道重跑、69 币 acc **逐位 max_abs_dev = 0.0**，这就是「它一动没动」的证据而不是引用）。**L4 的 0.6902 与 L0 的 0.6727 是两张考卷**，禁止并列成「提升了 1.75pp」（C3 硬纪律）。
4. **机制自洽**：口径变成 27 小时均值后，特征主人换了——`ewma94`（λ=0.94，最有效的平滑因果特征）gain 从 19.2% 跳到 **91.92%**，`col_lag0` 从 75.4% 掉到 **6.28%**；收益率组 + `rstd24` 合计 **0.0875%**。这是「模型在预测一个平滑量能水平」的直接指纹，也第三次复现了 E017/E019 的「收益类特征在这张任务上无量」。水平项上模型 MAE 0.29836 同时打赢参照持久性 0.35864 与当期量持久性 0.50408。
5. **一条被自己的测试证伪的实现**：C5② 的目标扰动测试第一版因把行号当有效 bar 下标而失败，修正后才过——它先抓出的是**测试的 bug**，不是构建器的 bug。同时实测 `label_info_end − t` 为 **27~51 小时**（窗口按有效 bar 数取，断档与死量 bar 会拉长它），这条披露影响任何「等到信息窗闭合」的成本估算。
6. **偏差**：C7（四件产物 sha1 两遍逐位一致）**按字面未过**——`metrics_by_coin.csv` 有 1 行 2 个浮点单元格（`mae_log1p` / `rmse_log1p`）差 1~2 ULP，而全部判定字段与另外三件产物三遍逐位相同。归因停在 **E3**：与「`n_jobs=4` 不保证逐位可重现」一致（`feature_importance.csv` 三遍全等 ⇒ 树结构未变），但**同配置在 E017 S5 实测通过两遍逐位一致**，所以不能写成「多线程必然漂移」。处置：不重跑求过、不改 `n_jobs`（那是 C4 锚臂逐位复现 E017 的复现对象，改它等于弄坏一个更强的门），事实留在 §3.5、日志 #71 与 `out/stage2_c7_deviation/`，并立 D052：**确定性门必须绑定判定字段，报告字段显式给容差**。
