## 1. 预注册（运行前填）

### 问题

用户拟训练「下一小时成交量方向准确率 >70%」的模型（动机：DCKD 论文教师 73.1% / 学生 72.8%，作者声称，E2）。在训练之前先回答：**这份 crypto 数据上，零训练基线（多数类 / 惯性 / 简单时序 / 日历查表）的样本外方向准确率是多少？70% 目标是否平凡？**

### 假设

- H1（跑前预期，E3，可被证伪）：up 基率在 45~55% 之间，最强基线 OOS acc（逐币等权）落在 50~56%，即 70% 是非平凡目标。
- H0（必须能接受的零假设）：基率本身 ≥65%，或某条零训练基线 OOS acc ≥70%——则「70%」不蕴含任何方向信息，目标平凡，照实写、不做补救实验（沿用 D042 第 1 条）。

### 判据

- **C1 主判定（跑前写死）**：最强方向臂 OOS accuracy（**逐币等权**，69 币）≥ 0.700 ⇒ 判「70% 目标平凡」；< 0.700 ⇒ 判「70% 非平凡，但未来模型必须超过最强基线才算学到东西」。pooled（行级混合）口径同报；两口径分居 0.70 两侧时按 D039 表述纪律写「口径敏感、不可分辨」并披露两侧数字。
- **C2 基率 farming 披露**：若最强臂 acc ≥ 0.70 而 balanced accuracy < 0.55，必须标注「高准确率主要来自基率 / 恒定预测，不含方向信息」。
- **C3 硬自检**：
  - S1 有效性：评分对必须满足原始时间戳差恰好 1h、双端 `volume > 0`；平局（`vol_{t+1} == vol_t`）剔除。自报逐级剔除行数（原始行 → 零量剔除 → 断档/跨死量剔除 → 平局剔除 → 判定行集）。
  - S2 防前视：所有臂在 t 时刻只用 ≤t 的信息；IS 统计（多数类、小时查表、小时均值剖面）只用 IS 行；断言 `a0_always_up` 的 acc 与判定行集 up 基率逐位一致（±1e-12）。
  - S3 查表稀疏（D043 第 3 条）：算任何判定数字之前先实测「OOS 判定行落在 IS n<30 的币×小时格的份额」，>20% 则 a7 不得进判据、本实验只报其余臂。24 格/币结构上预计 ≈0，仍须实测落盘。
  - S4 复跑验 sha1 逐位一致（本仓收尾惯例）。
  - S5 数据冻结：跑前把 69 个 bars 文件的行数 / 时间范围 / sha256 写进 `protocol.json`，跑后断言全部不变（并发会话只读共享，E012 正在跑 GARCH，本实验不抢核、不写 `data/`）。
- **输出建议（非判据，供用户拍板）**：未来成交量方向模型要算「学到方向信息」，最低门槛建议 = OOS acc > 最强基线 + 2pp 且 balanced acc 更高、逐币等权与 pooled 同向。此门槛是建议值，是否采纳、是否写进未来预注册，由用户决定。
- 停止条件：单次跑完即停；零训练、零调参、不补救；墙钟上限 10 分钟，超限记录并停。

### 数据

- 来源：`data/bars/1h/` 全部 **69 个 `*USDT.parquet`**（不含 `_MARKET`、不含 50 只 sh./sz. A股——本实验只做 crypto）。区间随各币上市时间 ~ 2026-11-08（BTC 2020-01-01 起，60,072 行）。
- 字段：`time / open / high / low / close / volume / amount`。**主口径 `volume`**（基础资产成交量）；`amount`（USDT 成交额，D035 已回填）用同一套代码再跑一遍作**稳健性报告项**，不进 C1。
- bar 有效性规则：双端 `volume > 0`（借 D036/D039 死量 bar 口径；本实验是方向分类，D039 原文范围是波动率实验，此处为本实验预注册自选口径并披露）。断档（含 2024-10-28 20:00 全站缺行与 5,042 根缺失小时，见数据伪影专题）由「Δt 恰好 1h」规则自动挡在评分对之外。
- 数据可得时点：标签是 t→t+1 的前瞻方向，评分用 t+1 收盘后已实现值；特征 / 预测侧一律 ≤t。

### 切分

- IS 2020-01-01 ~ 2023-12-31 / OOS 2024-01-01 ~ 2026-11-08（与 E005/E008 主线同边界，尾巴随数据延伸）。评分对两端都须落在 OOS 内。
- **判定行集 = 所有臂共同可评的 OOS 行**（惯性臂要求前一 Calendar 对 also 有效；MA24 要求 24 根前置有效 bar；其余臂在此行集上同样评分，保证臂间逐行配对）。各臂单独可用行数与共同行集剔除数披露。
- IS 统计只用 IS：逐币 IS 有效对 < 1000 的币（2024 后上市新币），a2 回退为**全币 IS 混合多数类**、a7 回退为**全币 IS 混合小时查表**；受影响币数披露。
- 逐年（2024 / 2025 / 2026）OOS 分解作报告项。

### 成本与成交

- 不接实盘、无成交假设。计算成本：零训练、向量化 pandas，预计 <2 分钟；上限 10 分钟。并发披露：另一会话 E012 GARCH 全量在跑（CPU 密集），本实验为轻量向量化读算，不重训、不抢核。

### 样本量与检验

- 69 币 × OOS 约 2.9 万对/币 ≈ 200 万判定行（精确数跑后落盘）。
- 本实验是基线测量不是模型检验，不做假设检验；C1 是跑前写死的描述性判定。逐币分布（中位 / 极值 / ≥70% 币数）全报，防止等权均值掩盖分布。

### 预期反例

- 若 up 基率 ≥65% 或任一零训练臂 OOS acc ≥70%（逐币等权），H1 即被证伪：70% 目标平凡或接近平凡，用户应把目标改成「超过最强基线 + 边际」而不是盯 70% 绝对值。照实写，不补救。

## 2. 实现

- 命令：`.venv/bin/python exp/E014-vol-direction-baselines/code/baselines.py`（pandas 3.1.1 / numpy 2.5.4，全向量化，零训练零调参）。
- 墙钟 **2.5 秒**（上限 10 分钟）；复跑第二遍五件产物 sha1 逐位一致（S4）。并发披露：另一会话 E012 GARCH 全量在跑，本实验只读 bars、未抢核、未写 `data/`。
- 与预注册的偏差：**仅一处产物格式修正**——恒定臂（a1/a2）precision/F1 无定义，首跑 JSON 落盘为 `NaN` 字面量（非严格 JSON），改为 `null` 后重跑；全部判定数字不变。无其他偏差。

### 臂定义（8 条方向臂，全部零训练或仅 IS 计数）

| 臂 | 规则（预测 pair t→t+1 的方向） | 信息集 |
|---|---|---|
| a0_always_up | 恒 1 | 无 |
| a1_always_down | 恒 0 | 无 |
| a2_is_majority | 逐币 IS 多数类（平局取 1；新币回退混合多数类） | IS 标签 |
| a3_inertia | = pair t-1→t 的方向（前一 Calendar 对须有效） | ≤t 成交量 |
| a4_contrarian | = 1 − a3 | ≤t 成交量 |
| a5_ma24_revert | vol_t < mean(vol_{t-24..t-1})（24 根**有效 bar**压缩窗口，shift(1)，min_periods=24）则预测 1 | ≤t 成交量 |
| a6_ewma94_revert | vol_t < EWMA_{t-1}（λ=0.94，adjust=True，序列起点初始化，shift(1)）则预测 1 | ≤t 成交量 |
| a7_hour_lookup | 币 × 目标 bar UTC 小时（24 格）IS 上涨率 > 0.5 则预测 1（=0.5 取 1；格 n<30 回退该币 IS 基率，新币回退混合查表） | IS 标签 + 日历 |

指标（每臂 × 每币、逐币等权、pooled，IS 与 OOS 同报）：accuracy@thr0.5（冻结）、混淆矩阵（up=正类）、precision / recall / F1（up）、balanced accuracy。

水平基线（**报告项，不进判据**）：persistence（vol_t）、ma24、ewma94、hour_profile（IS 币×小时均值按 t+1 小时取值）预测 vol_{t+1}，log1p 空间 MAE / RMSE，逐币等权 + pooled——回答「幅度能不能预测」的第一层参照。

## 3. 结果（E1）

产物：`exp/E014-vol-direction-baselines/out/`（`metrics_summary.json` / `metrics_by_coin.csv` / `by_year.csv` / `exclusions.csv` / `level_baselines.json` / `amount/` 同构）。关键数字落本文（`out/` 不入库）。

### 3.1 样本与有效性（S1）

69 币原始 **3,168,512** 行 → 零量剔除 **31,662** → 有效 bar 3,136,850 → 非 1h 相邻剔除 **171** → 平局剔除 **1** → 有效对 3,136,609。OOS 判定行集（全臂共同可评）**1,686,328** 行（逐币中位 25,002，最小 8,910 为上市晚的币）。IS 拟合对另计（统计只用 `next_t < 2024-01-01` 的对）。IS 有效对 <1000 的 6 个新币（JTO/JUP/PYTH/RENDER/STRK/TON）按预注册回退混合统计。

### 3.2 基率与八臂 OOS（主口径 volume，thr 0.5）

**OOS up 基率：逐币等权 47.40%**（中位 47.46%，逐币范围 45.78%~48.23%）；IS 同口径 47.05%。**「成交量增加」是少数类**——恒涨只有 47.4%，恒跌 52.6%。

| 臂 | acc 逐币等权 | acc pooled | bacc 等权 | IS acc 等权 |
|---|---|---|---|---|
| a0_always_up | 0.47397 | 0.47388 | 0.50000 | 0.47051 |
| a1_always_down | 0.52603 | 0.52612 | 0.50000 | 0.52949 |
| a2_is_majority（全部币 IS 多数=跌，与 a1 逐值相同） | 0.52603 | 0.52612 | 0.50000 | 0.52949 |
| a3_inertia | 0.41221 | 0.41212 | 0.41057 | 0.41322 |
| a4_contrarian | 0.58779 | 0.58788 | 0.58943 | 0.58678 |
| **a5_ma24_revert（最强）** | **0.62382** | **0.62375** | **0.63164** | 0.62617 |
| a6_ewma94_revert | 0.61995 | 0.61992 | 0.62864 | 0.62204 |
| a7_hour_lookup | 0.57587 | 0.57594 | 0.56970 | 0.58796 |

- **没有任何一币、任何一臂 OOS acc ≥ 0.70**（`n_coins_acc_ge_070 = 0` 全臂成立）；a5 逐币范围 0.6006（BTC）~0.6353（FLOW），前三弱 BTC/SOL/ETH 0.601/0.611/0.613。
- a5 混淆矩阵（pooled）：TP 624,789 / FP 460,161 / TN 427,056 / FN 174,322；等权 precision 0.5760 / recall 0.7817 / F1 0.6632。恒定臂 precision/F1 无定义（不预测正类），落盘为 `null`。
- 逐年等权 acc（a5）：2024 **0.6198** / 2025 **0.6224** / 2026 **0.6304**，三年稳定；IS→OOS 仅 −0.24pp（零训练臂本应如此）。
- **机制**：方向反持续——惯性 41.2%（低于抛硬币），反向 58.8%；成交量尖峰衰减驱动均值回归，MA24 回归 62.4% 为最强零训练臂。日历武装（小时查表）57.6%，低于同信息集的 MA24 回归。
- **amount 稳健性（报告项）**：基率 47.40%、最强臂同 a5、等权 acc **0.62334**（与 volume 差 0.05pp），八臂排序完全一致。

### 3.3 水平基线（报告项，log1p 空间，OOS 判定行集）

| 臂 | MAE 等权 | RMSE 等权 |
|---|---|---|
| persistence | **0.41653** | **0.54410** |
| ma24 | 0.50425 | 0.63055 |
| ewma94 | 0.50322 | 0.62524 |

方向上最强的均值回归臂在**幅度**上反而输给 persistence——「方向可回归」与「幅度可预测」是两个问题，幅度侧零训练最强参照是 persistence。

### 3.4 硬自检与跑前预期对账

- S1 有效性逐级行数闭合（§3.1）；S2 防前视：69/69 币 `a0 acc == 判定行集基率`（±1e-12）且 MA24 前 3 判定行逐币重算一致（只用 <t 的 24 根有效 bar）；S3 查表稀疏 **6.71%** ≤ 20%（全部来自 6 个新币，回退混合查表后覆盖）；S4 复跑五件 sha1 逐位一致；S5 跑后 69 文件 sha256 全部不变。
- **跑前预期对账**：H1 的基率带（45~55%）命中（47.4%）；但最强臂预告带 50~56% **被实测 62.4% 超出**——均值回归比跑前预期强，此条预期不中，照实登记；主结论方向（70% 非平凡）不变。

## 4. 结论

- **一句话：在这份 crypto 69 币 1h 数据上，70% 是非平凡目标（C1 = nontrivial_70，两口径同向）——up 基率只有 47.4%，最强零训练基线 62.4%，70% 比它高 7.6pp；「恒涨拿 70%」的担忧在本数据不成立。**
- 对用户原问题的直接回答：DCKD 的 73.1%（E2，作者声称）若基率/基线与本数据类似，则是有信息量的成绩；但他们是否报了基率与混淆矩阵无从核对（E2 不当结论）。**本仓若训成交量方向模型，判据锚应钉在基线上而不是 70% 绝对值**：建议最低门槛 = OOS acc > 64.4%（最强基线 62.38% + 2pp）且 bacc 更高、逐币等权与 pooled 同向（建议值，是否采纳由用户拍板，本实验不代拍）。
- 适用边界：crypto 69 USDT 1h、OOS 2024-01~2026-11-08（与主线同段已见数据，本实验是基线测量不是独立业绩）；标签为小时环比方向，换成日级/额口径结论可能不同（amount 口径已测，几乎相同）。
- 下一步：是否立项训练由用户决定；若立项，新预注册须带本实验的基线表与 D043 第 1 条两档参照。**本实验不训练、不改任何主线代码、不写 `data/`。**
