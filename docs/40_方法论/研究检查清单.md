# 研究检查清单

跑实验前逐条过；任何一条答不上来，先补，不要先跑。

## 问题与判据

- [ ] 问题能用一句话说清，且答案不是“看情况”。
- [ ] 假设可证伪：写明了什么结果算失败。
- [ ] 判据在运行前写下，不是跑完再编。
- [ ] 预期反例：什么结果会让我放弃。

## 数据

- [ ] 数据来源、标的池、周期、区间、复权、缺失处理明确。
- [ ] 只用当时可得的数据（无未来函数）；特征截断重放能复现。
- [ ] 幸存者偏差：退市/停牌/换合约的标的如何处理。
- [ ] 样本量与事件数足够；独立样本不是“同一波段的多个 bar”。

## 切分与验证

- [ ] 训练/验证/测试按时间切，不打乱。
- [ ] 标准化、特征选择、阈值冻结都只用训练期。
- [ ] 有真正的 OOS；不是“全量评估”或“按标的索引切分”。
- [ ] 多重检验：试了多少组参数/特征，是否校正。

## 成本与组合

- [ ] 单边成本、滑点、成交时点明确（A 股 13bp / BTC 12bp 起步）。
- [ ] 组合级回测含换手、容量、资金约束；不是只算事件平均收益。
- [ ] 尾部依赖：去掉 top1% 后是否还成立。
- [ ] 基线合理：同数据、同成本下的 naive/随机/单因子基线。

## 结论与留痕

- [ ] 结论只引用 E1；E2 写成“作者声称”。
- [ ] 关键数字可复算：命令、参数、产物路径齐全。
- [ ] 负结果同样记录；作废不删。
- [ ] 版本锁定：仓库 commit、数据版本、依赖版本。
