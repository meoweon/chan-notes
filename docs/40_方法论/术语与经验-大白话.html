一、术语表（大白话，按使用场景分组）

每个词三件套：大白话定义 → 一个类比 → 我们踩过的坑（有编号的都是真实发生过的事）。

A. 行情与数据
bar / K线 candle
把一段时间（比如 1 小时）的价格压缩成一个格子：开盘价、最高价、最低价、收盘价、成交量。我们全仓用 1 小时格。 类比：心电图上的一跳。1h bar = 每小时记录一跳。
收益率 ret
这一格价格变了百分之几。对数收益率是「用加法就能连乘」的版本，两种算法数字略有差别。
坑：成交量模型用简单收益率、波动率模型用对数收益率，两边都有叫 ret_lag 的列但根本不是一回事（决策记录 D050 记了三处这种「假朋友」）。列名像 ≠ 同一个东西。
已实现波动率 RV, realized volatility
「这段时间价格到底晃得多厉害」的测量值。我们的标签就是它取对数。 类比：体温。整个波动率线做的事就是「量体温 + 预测下一小时体温」。
GK / Parkinson 两种体温计
同一根 bar 的两种波动率估计公式：Parkinson 只用最高/最低价，GK 再加上开/收盘。它们估的是同一个 σ，只是噪声不同——所以外部参照把 6 列一起喂给模型，思路是给模型一个小小的估计器组合。 这一点很值钱：它说明「两列合起来更强」的真实机制常常是互相抵消噪声，不是发现了新信息。
log 空间
波动率取对数再建模。原值从 0.3% 到 300% 差一千倍，取对数后变成好算的窄条带；而且「波动率翻倍」在对数空间里是均匀的一步。
死量 bar dead bar
成交量为 0 的格子。E008 查明它是坏数据（该小时没成交记录），不是「安静的市场」——剔掉之后整条波动率线重训过一次。
尖峰 spike
突然放量的一格。E017 的模型 gain 94.6% 押在两列量状态上——它大部分工作其实是「现在在放量 → 下一小时回落」这条回归均值的分级判断。
B. 模型与基线
基线 baseline
出题之前先算好「笨办法能考多少分」。不写它，你就不知道你的模型到底带来了什么。 类比：先让全班 averages 站上跑道，你的选手快没快，是相对出来的。
免费规则 a5 等
一条 if 就能算、零训练的规则。E021 实测：免费的 a5 规则在方向和波幅两个指标上全部不输训练过的模型。
武装基线 armed
给笨办法喂上日历、持续性这些「小抄」，让它变强之后再当裁判。目的：防止你的模型只是靠琐碎信息取胜。 类比：陪练先穿上护具。打赢光膀子的陪练不算数，打赢穿护具的才算。
persistence / naive
最笨的两个基线：「明天的量 = 今天的量」「明天的波动 = 今天的波动」。别小看它们，波动率自相关性很强，这两个对手相当能打。
HAR
把 1 天、1 周、1 个月三个尺度的平均波动率加权相加的线性公式。波动率预测领域几十年的老基准。E016 的翻案本质上就是「HAR 的三个尺度怎么选」——从手调换成规则生成后，我们的树模型才第一次打赢武装参照。
EWMA / GARCH
两个递推式波动率模型。EWMA = 加权平均，越近权重越大（我们用 λ=0.94 的版本）；GARCH = 「今天的波动」和「今天的意外冲击」两个方程互相滚动。E011/E012 在 crypto 上它们都输给武装参照。
LightGBM / XGBoost 树模型
一大群「如果…那么…」的判断叠起来的模型。我们的主力是 LightGBM（crypto 上两者打平，A股上 XGBoost 的 MSE 略好但 QLIKE 差 19 倍，所以不换）。
gain 份额 / 特征重要性 用了 ≠ 有用
树模型训练时某列被用了多少比例。它只说明「被使用」，不说明「有贡献」。
坑（E009）：把 gain 第 3 名的列裁掉，模型成绩无损；把 gain 第 158 名的列裁掉，成绩反而掉了。别拿 gain 当结论，只当线索。
C. 评价的尺子
QLIKE
波动率预测专用打分，越小越好，对「低估」罚得特别重。 为什么用它：低估波动会让你重仓去挨打，所以低估的代价必须更贵。
MSE 均方误差
误差平方再平均，越大罚越狠。波动率线和 A 股线用它。
acc / Δpp 答对率 / 百分点增量
方向题（下一小时量涨还是跌）的答对率；Δpp 是两个数字的差。所有 70% 目标的判定只认固定 0.5 阈值的 acc——这是我们冻结过的口径，别的花哨阈值一律不算。
CI / bootstrap 置信区间
「这个数有多大把握」。把样本有放回地重抽一万遍，看数字散布在哪。两条硬规矩：CI 跨过 0 = 不能断言有信号；逐币的 CI 要按「币簇」抽（同一天的币互相不独立）。
逐币等权 vs pooled
逐币等权 = 每个币一票再平均；pooled = 全部行混在一起算。pooled 会被大币和尖峰行绑架，所以我们主判据用逐币等权，pooled 只作参照。
判定行集
到底哪些行参与算分。行集一变数字全变，所以必须冻结并和上游逐位对拍（E016：判定行 1,205,982 = 上游，一行不差）。
尺子同源
判据代码只能从一个地方 import，不许抄写——抄写一定会抄错。E017 复用 E014 的评分代码，自检 120 项差值恰好 0.0。
D. 纪律与方法（这个仓的交通规则）
预注册
跑之前把「判据、数据、切分、预算、停止条件」写死落盘。跑完之后不许改。它防的是最隐蔽的敌人：跑完挑好看的那个数字。
三段授权
注册（只读+写预注册）→ 你授权跑 → 写回（判定+台账+决策记录）。每段停下来等你点头，机器不会自己往下走。
非平凡门 C1 门
进模型阶段之前，先测「零训练能白送多少分」。E020 用这道门淘汰了三个标签口径——它们白送 73%~83%，考它们等于开卷考试。
坑：如果没这道门，我们会花几周把「白送 83%」的口径调到 85%，然后以为模型很厉害。
IS / OOS 练习册 / 期末考
训练段（in-sample）和考试段（out-of-sample）按时间切开。模型只准看练习册。
前视泄漏 & shift(1) 最贵的错误
用了 t 时刻还看不到的信息 = 偷看考卷。数字会漂亮得离谱，实盘立刻现形。防法：所有特征整体前错一根（shift(1)）。上游仓库用两个测试盯着：往未来注一根尖峰看特征变不变、扰动当天价格看特征变不变。
坑（今天的新鲜案例）：把 E017 的量列搬进波动率面板时，col_lag0 含当期——而波动率标签恰好是当期 bar 的振幅。直搬 = 把答案印在考卷背面。必须重挂一根。
purge / embargo 边界隔离
标签要跨很多根 bar 时，训练段尾巴和考试段开头之间要留空隙，防止滚动窗口跨边界「借到」考题。E020 实测边界真的起了作用（多剔了 1,690 行）。
逐位复现 & 门槛分层
同一份输入重跑，判定用到的每个字节都必须一样（判定层零容差）；不进判据的浮点列（比如 MAE 报告值）允许显式容差（报告层）。计时、版本这类每次必变的字段隔离到单独文件，不然门永远过不了（D052/D053）。
E1 / E2 / E3 证据分级
E1 = 源码、可复算产物（结论只准用它）；E2 = 作者声称/README（只能写「作者称」）；E3 = 推测类比（必须标注，不能当结论）。今天外部参照那张 vol_target 表是 E1（可复算产物），但样本是美股指数，只能当结构启示、不能横比数字。
作废不删
错的结论标记「作废 + 原因 + 日期」留着，不许删。E021 当天我口头报过一个 2.45× 的数，落盘复现不出来，作废留档——防止历史被悄悄改写。
输出层 vs 特征层冗余 只差一层，结论相反
输出层：A 的预测被 B 的现成数字压制 → 「A 没有交易岗位」；特征层：B 的输入里已经含 A 的信息 → 「A 不必再采集」。E021 判的是前者；波动率面板一列量都没有，所以后者从未测过——这正是 E023 候选存在的理由。
E. 钱那一层（全仓最空、也最重要的一格）
仓位 position
这一笔拿多少钱去冒险。波动率预测最终服务的对象就是它，不是「预测本身」。
波动率目标 vol target
想让组合每年晃 15%，就用 仓位 = clip(0.15 / 预测波动率, 0, 2) 定每期仓位——预测到晃得厉害就减仓。外部参照源码原话。这是「预测 → 钱」的最简单一条桥。
换手 turnover
仓位变来变去的幅度总和。换手越高成本越贵。外部参照实测：最准的 LSTM 换手最高，最不准的 GARCH 只有它的四分之一左右——差数倍。
交易成本 / 净 Sharpe
每回合扣几个 bp（万分之一为单位），扣完的 Sharpe 才是真 Sharpe。上游实测扣 5bp 后，最准的模型净值反而垫底。
最大回撤 max drawdown
净值从最高点往下掉的最深坑。vol target 策略把回撤从 −80% 压到 −15%~-22%。
开仓门槛 threshold
信号强过多少才动手。规矩：阈值用「精度-阈值曲线」定，不许在考试段上搜——在考卷上挑阈值就是作弊。
QLIKE → 钱的那一环 本仓从未测过
「预测更准」和「账户更有钱」之间隔着策略、换手、成本。我们 20 多个实验全部停在 QLIKE / acc，从来没有一个实验测过下游决策。这一格是空的，而且它不是靠加特征能填的。

二、经验总结：这一程真正学到的十条

每条格式：结论一句话 → 数字证据 → 以后怎么用。编号对应真实实验，可回查。

  1. 1. 标签决定上限，特征只决定你离上限多近。
    证据：成交量方向的基率只有 47.4%，最强免费臂 62.4%（E014）——上限就在那里摆着；换标签口径后三个口径被证明笨办法白送 73%~83%（E020 的非平凡门）。你的原始目标 70% 在 L0 口径下到底可不可达，是标签的属性，不是模型的属性。
    怎么用：任何「模型不够好」的念头，第一步先问「这个标签本身还剩多少可预测性」，先跑免费基线，再谈模型。
  2. 2. 特征越多越好是错觉。机器只会在你给的信息里找最强的一条路，它不会告诉你别的路有没有走平。
    证据：21 列里 2 列吃掉 94.6% 的 gain，全部收益率类合计 0.074%（E017）；新抓 8 列外部数据只值 +0.126pp（E019）；上游把 7 列宏观/利率放进面板，gain 合计只有 5.03%，而 2 列波动率滞后占 68%；连「抓因子」的脚本都写好了却一次没用（fetch_ff_factors.py:3 自称 "Not required by the volatility pipeline"）。
    怎么用：加特征前先回答「它和已有的最强列比，机制上多了什么」。答不出机制，先登记成待测格子，别急着抓数据。
  3. 3. 「两列合起来更强」的真实机制常常是噪声对冲，不是新信息。
    证据：GK 和 Parkinson 是同一个 σ 的两支体温计，外部参照注释给出的思路是估计器组合。
    怎么用：看到两个相似列合并后涨分，先问「是新信息，还是把标签本身测准了？」——后者叫改进测量，前者才叫发现信息。两者的可复制性天差地别。
  4. 4. 「A 的信息 B 已经有了」必须分输出层还是特征层说，两层只差一层、结论完全相反。
    证据：量模型输出在方向上无岗位、在波幅上被 rstd24 压制 3.1~3.4 倍（E021）——这是输出层；但波动率面板 19 列里一列量都没有（features.py:43 量只当过滤器用完即丢）——特征层从未测过。把前者说成后者，会把唯一开着的实验方向以「已经做过」的名义关掉。
    怎么用：说「冗余」之前给两边特征的构造行号 + 一条同台实测（D050 三条规则）。
  5. 5. 基线不是礼貌，是裁判。
    证据：E021 里免费 a5 规则在方向和波幅上全部不输模型；E016 的翻案恰恰是靠把参照「武装」起来之后才看清谁强谁弱；E012/E011 双侧判负也是武装参照给的。
    怎么用：任何判据旁边必须站着一个免费对手。打赢光膀子的笨办法不算数。
  6. 6. 准 ≠ 赚钱。模型之间差距很小，「用波动率调仓」这个动作值 0.30。
    证据（外部参照的 vol-target 表，美股指数日线，结构启示）：点预测精度排名与净 Sharpe 排名基本不一致；几个模型的净值几乎并列，而「恒定 1x 买入持有」明显更低。钱的九成来自调仓动作本身，模型谁准只值很小一部分。换手差数倍，成本与精度反向。
    怎么用：波动率线的价值主张要改写成「供仓位决策用的风险预测」，并且要用一张净 Sharpe/回撤/换手的表来验收——这是全仓缺的那张考卷。
  7. 7. 参数不调，协议存规则不存手调数。
    证据：E016 翻案的根源就是把「手调的 (24,120,528)」换成「规则生成的 (1,27,720)」——手调数只在你测过的那段时间成立，规则可以跨频率迁移并自检。超参数已按你的拍板冻结（2026-11-10）。
    怎么用：任何数字进协议前问一句「换个市场/频率它还对吗」。对不了，就写成生成它的规则。
  8. 8. 结论只认可复算的 E1，连上游的成品都会腐烂。
    证据：外部参照的特征重要性表里 ret_1d 排在前列，但他们现行代码已把该列删掉、测试里还有断言不许它存在——表是旧版代码产的（未重跑，此归因属 E3）。同类教训：E021 我口头报的 2.45× 复现不出来，作废留档。
    怎么用：引用任何数字前，找到落盘产物或重算命令。「作者的 CSV」≠「作者的代码现在会产出的东西」。
  9. 9. 同名不同义会双向出错，而且不会报错。
    证据：三处假朋友——ret_lag 一边是单根滞后一边是滚动均值；ma24 一边不含当期一边含；volume 一边是过滤器一边是主输入（D050）。另有 ma24 同名列覆盖 bug 被硬自检抓到（D047）。这些错位只会让两套数字「看起来互相印证」。
    怎么用：跨模型比较或拼列前，先核 shift 语义和窗口含不含当期，差异表落盘；列名相交就加前缀 + 断言。
  10. 10. 纪律即效率：预注册、三段授权、门槛分层，都是为了让「错了能早死、对了能复算」。
    证据：E020 的非平凡门在训练前就淘汰了三个口径（省下的机时不可考，但省下的弯路可考）；E016 的机时超限事件催生了「机时按所有尝试之和计」的口径；确定性门分成判定层/报告层后，一次 17.8 秒的加跑就能定位漂移在哪一层（D052）。
    怎么用：感觉「流程繁琐」的时候，回想它们各自拦下过什么。每一层繁琐都对应一次真实翻车。

三、把流程换成五步（可带走的操作法）

你现在的直觉流程：收集特征 → 喂模型 → 希望它好。换成：

  1. 这个标签有多少可预测性？——先跑免费规则和零训练臂，把天花板量出来（E014/E020 在做）。
