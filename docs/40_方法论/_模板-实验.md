- 停止条件（样本/时间/成本上限）：
- 单 bar 已实现波动率实验（log 空间标签）的两条强制披露（D041）：① QLIKE 除「地板行自身对各指标的份额」外，**必须同时报「地板行的下一根有效 bar 对 QLIKE 的份额」**——persistence/HAR 会把地板标签复制进预测，下一行真值回正常时 `exp(2d)` 爆量级，只报前者会得出「未触发披露」的假阴性；② 参照组**必须含一张只用 IS 拟合的「标的 × 日历时段」查表**（零波动信息），并写明候选相对这张表的位置，否则「优于双基线」可能只是基线缺一个时段变量
- 参照组最低要求（D042 第 2 条，E011 实测后新增）：判定「要不要用机器学习模型」时，参照组除 persistence/HAR 外**必须同时包含（a）与标签同一信息集（四价）的传统模型（EWMA-on-GK / GARCH-on-logRV 一类）和（b）同一套日历武装的传统模型**，并以其为判据对象。只比 persistence/HAR 得出的「候选优于基线」不再算回答——E011 里候选连只看收盘价的裸版 EWMA/GARCH 都没打过（QLIKE 0.732/0.744/0.671 vs lightgbm 3.117）
- QLIKE 倍数不引用（D042 第 3 条）：在**判据口径**下（逐标的等权，每行对差距贡献 = `gap_i/(N·n_ticker)`）预注册一条**双侧对称**规则——某条比较的 QLIKE 差距有 >50% 来自不超过 5 行，则该条 QLIKE 侧一律写「不可分辨」并列出这 5 行的归属（地板行 / 地板下一根 / 零收益 bar 之后 / 滞后特征深谷），不得挑对自己有利的一侧；该样本段上「A 比 B 好 N 倍」的 QLIKE 表述一律不引用，只引用剔除被点名行后的量级 + 方向（E011 实测 18/18 条触发，剔 5 行后 961×→24×；MSE 的 top5 行份额仅 0.03~0.07，不需此规则）
- 跨实验继承上游口径时（D042 第 5 条）：必须用**上游的评分函数**重算上游已报的每一个判据数字并断言差值为 0（E011 的 S11-7 即范例），只写「沿用同一口径」不算证据
- 分类器 / 事件打分线的参照组最低要求（D043 第 1 条，D042 第 2 条的一般化）：凡判据写成「要不要用机器学习模型」，参照组除弱基线（persistence/HAR 一类）外**必须含（a）与模型同一信息集的传统或查表参照、（b）同一套日历（必要时加身份）武装的参照**，并以后者为判据对象。只报「模型宏 AUC = 0.699」或只跟没喂饱的基线比，不算回答——模型与基线之间那点差距可能全部归属「基线缺一个变量」，E013 的跑前点验就实测到 202 列里**零日历列、零身份列**
- 格子型参照（分组计数为形式的参照臂）跑前自检（D043 第 3 条）：必须在**算出任何一个判定数字之前**实测「测试行落在训练格 n<30 的份额」（逐折中位）并写进判据，份额 >20% 的分箱/交叉设计不得进判据；连续变量的分箱档位（三分位 vs 四分位）与日历/身份的接入形态（**加法对数几率武装** vs 全交叉格子）由该份额决定。E013 的实测（**原文记「三分位 0.053 / 四分位 0.286（首折 0.784）」，2026-11-10 跑后经 `sparsity_diag.py` 复算作废：那是阶梯抄错一格——三分位（=实跑 L1）真值 0.2821、四分位真值 0.4066**）：`hour × dayofweek` 全交叉 2,506 格爆表；**结果：照改后的三分位仍然触门，E013 的判据对象 L1 被自己的稀疏度条款作废，判「不可比」**
- 跑前点验的两条硬形式要求（D044 第 1/2 条，E013 付学费换来）：① 凡被用来决定臂设计或门槛的实测数（稀疏份额、格数、每格行数、档位分布），必须由**脚本产出并落盘**（CSV/JSON），预注册里只写产物路径 + 数值，禁止从对话或人工读数抄进文档；② **门槛口径与披露口径必须是同一个表达式**——「未见格份额」与「n<30 行份额」在 E013 的 L1 上差 0.0065 vs 0.2821（43 倍），一个过门一个不过，凡写「稀疏/覆盖/份额」须在同一行注明分子分母与阈值变量名
- 格子型参照注定触门时不得作判据对象（D044 第 3 条）：跑前实测已 >20% 的话，二选一并写进预注册——换不被切碎的形态（**层级回退**：格 → 少一栏母格 → 全局基率；或**独热加权求和**），或主判据改问不受格子影响的问题。已跑完的实验按「不做补救实验」照原样接受不可比（D044 第 4 条同时规定：协议重冻只允许在零判定数字时发生，且须在 §6 写明两次之间改了什么）
- 逐标的参照臂（EWMA / GARCH / 标的×时段查表一类）必须预注册「晚上市与零历史标的」的处置（D045 第 4 条，E012 付学费换来）：三选一写死——① 最长可辨识滞后**前缀**退化（如 `arch` 的 `maxlag < nobs` 逼出的 `[24,120,528]→[24,120]→[24]→[]`）；② 该臂该标的-折记 NaN 并登记；③ 整条比较作废。选 ①/② 必须同时披露受影响行数与份额、归属（`标的/折`）清单、**方向判断**（退化通常让对手更弱 ⇒ 阴性偏保守），并给一个剔除受影响标的的敏感性读数（E012：2 币-折 / 1,183 行 / 0.109%，43/45 币重算 C1′ 形态不变）。禁止现场 `raise` 停机或悄悄跳过
- 结构性 NaN 只能**全臂对称剔除**（D045 第 5 条）：上游候选若是 pooled / 截面训练，零历史标的在候选侧有分数、在逐标的基线侧结构上不可能有分数。规则：凡某臂因结构性不可算出现 NaN，该**行**对所有臂（含候选）一并剔除，并断言「NaN 行集 ⊆ 已登记的零历史标的-折集合」，否则硬失败（E012 的 S12-2）。只从基线一侧消失等于让候选在对手的缺分行上得分
- 估计窗边界必须用显式 `side` 声明并与切分侧同严格性对拍（D045 第 6 条）：`searchsorted(cutoff, side="right") - 1` 在 24×7 小时数据上会取到**恰好等于 cutoff 的那根 bar**（该 bar 必然存在），与切分侧 `times < cutoff` 不一致——这是边界形态的前视。估计窗上界一律用 `side="left"`，并在每次折循环断言 `times[cut] < cutoff`（代码级 + `test_no_lookahead.py` 各一处）。**若在已有全量产物后才发现问题：产物作废重跑**，不许只在文档里补一句「影响很小」
- QLIKE 触发率可读作数据质量探针（D045 第 3 条）：同一条 ≤5 行规则在 A股 触发 18/18、在 crypto 触发 2/18（专题结论 14）。所以「一个 QLIKE 实验全触发」先怀疑样本段而不是先怀疑损失函数；反之也不得据此裸引倍数——引用前须用同一函数复算该口径 top5 份额并同行标出
- 滚动窗 / 滞后窗一类结构参数**由规则生成，协议存规则不存手调数字**（D046 第 1/2 条，E016 立项时定）：写法是 `rho`（每日历天行数，逐面板实测，不假设 24×7 也不假设有周末）→ `N_slow = round(慢锚日历天 × rho)` → `h_j = round(N_slow**(j/(K-1)))` 对数等距 → `h_0 = 1`；换频率只改 bar 秒数。规则必须过**外部效度自检**——把 ρ 代成上游论文的采样密度要能长出上游手调的那组数（E016：代回美股日线 ρ=252/365 得 `(1,5,21)`，原版 `(1,5,22)`，逐元 ≤1 且偏差只来自「一个月」取 30 日历天还是 22 交易日），断言脚本跑通才算参数可用；只写「这组窗口看起来合理」不算证据。两条配套硬要求：① 标签为单 bar / 单日已实现波动率时**快锚必须 `h=1`**（等价 lag-1；`rolling(1)` 数学上就是 lag-1，按日历倍数放大窗口会把它静默删掉，属口径缺陷不是设计选择）；② 改窗口必须 **paired**——候选与 HAR 族参照同时生效，只给一侧补快档是制造反向不公平（与 D042 第 2 条同罪，方向相反）

- **继承上游数值门槛（逐位/相对误差一致性类）时，跑前必须同时注册「门槛未过时的 materiality 分支」**（D049 第 1 条，E016 付学费换来）：写法是三步——① 先断言「我的复刻 == 出货产物」逐位相同（不同则归因不作数，硬失败）；② 把分歧量塞进递推/上游公式，测**判定列**的最大绝对变化；③ Δ=0.0 ⇒ 放行条件替换为同一对象的逐位不变量，并把注册原值 + `gate_*_numeric_passed=false` + 实测值一起留在产物里（**不改写注册门槛**）；Δ>0 ⇒ 按预注册判「不可比」，不出判据数字。**门槛严重性按「有没有落进判定列」分档，不按「相对误差多大」分档**——前者是判据的性质，后者只是尺子的性质。E016 实例：S16-5 继承的 1e-12 在 C1/C2 实测 9.02e-4 / 6.72e-3（超 3~4 个数量级），量得判定列 Δ=0.0（`baselines.py:194` 对 `kind="rv"` 取 `med = mu`，中位数不走方差递推）后放行，非判定的 `*_mean` 列 ≤6.05e-4
- **凡改结构参数（窗口 / 滞后 / 尺子），判据参照侧要注册估计稳定性披露集**（D049 第 2 条）：最差币-折定位、该折的判据读数、回归/均值方程系数的绝对值最大、拟合值 min/max、以及**同币-同折的成分消融**（删哪个分量能治好）。E016 实例：h=1 与月级慢锚共存时 `har_garch_rv` pooled 变 5.65e24 / inf / 39.8，逐币中位数却正常（0.60~0.62），全部由单币-单折决定（coef 最大 1363），消融删 h=1 或删最慢窗即恢复到 0.40~0.66。**≤5 行伪影规则是双向阀门**：它同样会被参照自身 MLE 崩溃触发，所以标签命中时必须在同一节写明分歧来自「参照自己拟合崩溃」还是「真实极端事件 + 参照正常」——前者说明参照在该配置下不可用，后者说明判据被少数样本主导；只写机械标签会让读者得出与数据相反的印象
- **机时超限按「是否产生部分完成的判定数字」分两种口径**（D049 第 3 条）：部分完成 ⇒ 判「不可比（机时超限）」并报已完成折数（E008 先例 `f5f53b4`）；**完整完成但墙钟超预算 ⇒ 照出判据数字、照记偏差**，把纯算力与各次被中止的尝试分开列（中止的按所有尝试之和计），不得用「反正跑完了」把预算声明抹平。为容纳中断把执行层改成逐折增量落盘（`out/parts/.../{fold}/meta.json` 作完整性标记 + windows/protocol_version 守卫）属允许的改动，但要在变更记录写明它改变了执行形态而不改读数
- **确定性门（「复跑一遍产物 sha1 逐位一致」类）必须分两层写，并由脚本自己跨遍断言**（D052 第 1/2/3 条，E020 阶段二 C7 字面未过换来）：*判定层* = 判据表达式实际消费的名字（`tp/fp/tn/fn`、acc/bacc/pooled、Δ 与判定串、行计数、协议 sha、逐位复现上游的 `max_abs_dev`）⇒ **零容差**；*报告层* = 不进判据的浮点列（MAE / RMSE / gain 份额 / CI 分位）⇒ 注册时二选一，**给显式容差**（本仓量级 `abs_dev ≤ 1e-9` 或「末位 N ULP 内」）**或写明「只披露、不参与门」**。分层依据是「有没有被判据消费」这个可机械检查的事实，不是「误差多大」。**禁止**只贴一个整份文件哈希当唯一门（那是可复算性的充分不必要条件），也禁止把跨遍比对留给人工——人工比对不会失败，只会忘记做。配套两条：① 计时 / 版本 / 哈希清单这类**每次必然变化**的字段要隔离到单独产物（E020 的 `runtime.json`），否则门永不可能过；② 字面未过时按「先定位再分档」：加跑一遍（本案 17.8 秒）→ 分别断言「判定层有没有漂 / 报告层哪些列漂 / 新遍等于哪一遍」→ 判定层零漂移 ⇒ 写「按字面未过、实质判定成立」并照常引用判据数字，判定层有漂移 ⇒ 判「不可比」。**两种「让它过」的路径一律否决**：重跑到干净（把判定建立在采样成功事件上），以及改冻结的学习器配置（`n_jobs=1` / `deterministic=true`）——后者会弄坏更强的门，因为协议里的学习器配置正是锚臂逐位复现上游的**对象**。登记归因前先 grep 同配置反例（E017 在同配置下 S5 实测**过** ⇒ 只能说「该配置不保证逐位可重现」，不能说「必然漂移」，归因停在 E3）
- **失稳与触门是两条轴，处置要落在产生失稳的那一层，份额引用要同行报量级**（D051 第 1/2/3 条，E022 零算力先验实测）：① 凡是「pooled 读数与逐标的中位数背离」这类参照可靠性问题，判据只能用**轴 A**（`log10_gap_pooled_vs_median` + `pooled` 有限性，非有限一律判失稳），而**轴 B**（D042 第 3 条的 ≤5 行份额）只是披露装置、**不得用来推断轴 A**——E022 实测触门集合的距离区间 [0.009934, 178.363] 下界**低于**非触门集合上界 0.060808，即触门里既有参照崩溃也有参照稳如常的真实极端事件；门槛必须由**本实验实测稳定带**按规则生成（`gate_b = ceil(安全系数 × 非触门上界, 0.1)`，系数与敏感性一起写进产物），引用别处的门槛数值等于跑前挑数；标签用词分家「**参照不可用（估计崩溃）**」vs「**不可分辨（≤5 行主导）**」，同时命中两个都写。② 处置表定主臂前先做**纯算术预检**（剔前/剔后各算一遍份额与差距，不重拟合）：失稳来自估计量时行侧处置（剔行/盖行/换行集）只作披露——E022 实测 8 条触门里 **6 条**剔 5 行后仍触门，而剔行对窗口无关判据对象的扰动 ≤4.0e-7，即「不伤判据也不治病」。③ 引用 ≤5 行份额的同一句**必须报总差距量级**：份额是无单位比值，分母趋零时**可 >1 且不保序**（E022 实测 C0 vs `naive` 剔前 −3.06e−03 / 份额 3.14 → 剔后 **+6.55e−03 / 份额 7.97**，符号翻转）
