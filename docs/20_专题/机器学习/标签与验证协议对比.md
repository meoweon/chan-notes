# 专题：缠论机器学习标签生成与验证协议对比

> 更新：2026-11-07 · 状态：草稿

## 问题

在相同的 `chan.py` 买卖点（BSP）触发事件基础上，`chan-quant` 与 `chan-model-xgb` 如何定义监督学习的预测目标（标签 $y$）、入场与退出规则、交易成本以及样本外（OOS）验证协议？为什么两套工程报告的模型评估指标（如 `xgb` 自报 AUPRC `0.944` vs `quant` 收益预测 AUC `0.50–0.55`）会出现数量级差异？

- **研究边界**：覆盖两项目的事件入场时点、打标函数（止盈/止损/时间窗口/删失处理）、训练/验证/测试切分、Walk-Forward 实现及组合回测终审逻辑。
- **前置关联专题**：特征矩阵 $X$（263 列）的定义对比见 [特征工程对比与实证.md](特征工程对比与实证.md) 与交互式看板 [ML可视化.html](assets/ML可视化.html)。

## 结论（E1）

1. **入场基准与确认机制截然不同**：
   - `chan-model-xgb` 直接以 BSP 触发当根 K 线的**收盘价**（`snap.close`）作为入场价（`train.py:114`），无次根开盘延迟；虽然独立脚本 `signals.py` 写了 3 根 K 线滞后确认滤波器，但训练打标函数 `label_bsp_snapshots()` 完全未调用该滤波逻辑。
   - `chan-quant` 严格按决策 bar `t` 的**下一根开盘价**（`opens[t + 1]`）入场（信号口径，`core/replay.py:112-113`），并提供**二次确认入场口径**（`labels/confirm.py:5-14`）：要求在 `t + 1 .. t + 4` 内收盘价突破信号 bar 高点（买）或低点（卖），于突破 bar 的下一根开盘价 `open[i + 1]` 入场。
2. **`chan-model-xgb` 的打标函数存在 4 处源码级缺陷（E1）**：
   - **单边止盈、无止损路径检查**：在未来 `1 .. 24` 根窗口内，只要最高价（买）或最低价（卖）触及目标阈值即判 `label = 1` 并退出循环（`train.py:131-141`），完全忽略触及止盈前是否已大幅跌穿止损。
   - **`min_window = 3` 为死代码**：注释与配置称“最短 3 根后才算达标”（`train.py:55`、`config.yaml:88`），但循环从 `bsp_idx + 1` 开始一旦触及阈值立即 `break`，第 143–145 行 `if (t - bsp_idx) >= min_w and label == 0: pass` 为空操作。
   - **全期 ATR 中位数前视泄漏**：高低波动自适应阈值使用全历史序列的 `np.median(atr_values)`（`train.py:82`），将未来波动率分布混入历史打标。
   - **成本乘数错配**：代码注释写 `价格目标 + fee_rate × price + slippage × price`（`train.py:60`），但实际代码写成了 `threshold_distance = effective_atr_mult * current_atr * (1 + fee + slip)`（`train.py:105, 125`），把费率乘在了 `ATR` 而非入场价格 `entry` 上（少扣了约 $1 / \text{ATR\%}$ 倍成本）。
3. **`chan-model-xgb` 的验证与时间切分存在严重的样本内泄漏（E1）**：
   - **Walk-Forward 按币种拼接行号切分而非按时间切分**：`train.py:576-578` 将 5 个币种样本按币种顺序纵向拼接（`np.vstack`）后未按时间戳排序；`walk_forward_split()`（`train.py:211-244`）虽接收 `timestamps` 参数却完全未使用，直接按数组行号切分，变成“用前几个币种的 2023–2026 全周期数据训练、预测后几个币种”。
   - **时间切分评估（`_evaluate_time_split`）实为 100% 样本内重测**：`train.py:336-341` 先用全量数据 `dtrain = xgb.DMatrix(X, label=y)` 训练出 `final_model`，随后在 `train.py:600` 将该模型传入 `_evaluate_time_split()` 计算“训练集/验证集/测试集 AUPRC 与泛化差距”（`train.py:465-520`）。由于 `final_model` 已经见过测试期全部样本，其测试集得分与 Ensemble 评估（`train.py:678-718`）均为样本内（In-Sample）结果。
4. **`chan-quant` 建立了防前视打标与月度隔离 Walk-Forward 闭环（E1）**：
   - **多维标签与右删失剔除**：同时生成固定期限前向标签（`H = 8/24/48` 的 `ret / dir_ret / mfe / mae / stop`）、先止损后时间退出的策略模拟标签（`pol_ret` 24bar/2ATR、`pol144_ret` 144bar/3ATR）以及结构存活标签（`clear_bar`）；数据末端不足持仓期且未触止损的样本显式标记为 `"censored"` / `NaN` 并在训练前剔除（`core/policy.py:55`、`scripts/train_wf.py:37`）。
   - **标签成熟期隔离（`matures_days = 28`）**：月度滚动训练时，测试月 `m` 的训练集截止于 `m.start_time - 28 days`（`scripts/train_wf.py:42`），确保持有 144 根 30m K 线（约 18 个交易日 / 26 个日历日）的训练标签在测试月开始前已完全结算。

## 证据

### 1. 打标逻辑与入场/退出规则逐项对比（E1）

| 维度 | `chan-model-xgb` 源码实现（E1） | `chan-quant` 源码实现（E1） |
|---|---|---|
| **入场时点与价格** | BSP 所在 bar `t` 的**当根收盘价** `entry = snap.close`（`src/chan_xgb/train.py:114`） | 信号口径：`t + 1` 开盘价 `opens[t + 1]`（`core/replay.py:112-113`）；确认口径：`t + 1 .. t + 4` 内收盘突破 `high[t]/low[t]` 后的下一根开盘价 `open[cidx]`（`labels/confirm.py:5-14`） |
| **预测标签种类** | 单一二分类 `y ∈ {0, 1}`（`train.py:42-160`） | 32 列基准标签（信号/确认 × `forward_labels` 20 列 + `policy_labels` 4 列，`features/build.py:46-59`）+ `pol144_ret`（`scripts/make_v5_label.py:24-30`）+ 结构存活标签（`core/replay.py:66-74`） |
| **止盈 / 止损机制** | **仅有止盈触及判定，无止损**：未来 `[1, 24]` 根内 `high >= entry + thr`（买）或 `low <= entry - thr`（卖）即标 `1`（`train.py:131-141`）；可选遇反向 BSP 提前标 `0`（`train.py:148-155`） | `simulate_exit()` 逐 bar 先检查是否触及止损 `entry ∓ stop_atr * atr`（买用 `low[i] <= stop`，卖用 `high[i] >= stop`），未触止损则在第 `hold` 根收盘平仓（`core/policy.py:25-56`） |
| **交易成本扣除** | `cost_factor = 1 + 0.001 + 0.0005`，错误地乘在 `ATR` 距离上：`thr = mult * atr * cost_factor`（`train.py:105, 125`） | 往返成本 `DEFAULT_COST = 0.0013`（A 股 13bp），直接从收益率中扣除：买 `raw - cost`，卖 `-raw - cost`（`core/policy.py:45-54`、`labels/label.py:45-46`，#37 修正卖侧符号） |
| **末端删失处理** | 仅剔除最后 `min_window = 3` 根内样本并强行标 `0`（`train.py:110-112`），倒数 `4 .. 24` 根内未满观察窗样本直接当负例 `0` | 观察窗不足 `H` 根且未触止损时，`forward_labels` 置 `NaN`（`labels/label.py:37-40`），`simulate_exit` 标 `reason="censored"`（`core/policy.py:55`），训练时剔除 `NaN` |
| **打标期未来泄漏** | `atr_median = np.median(atr_values[atr_values > 0])` 使用全期 K 线计算中位数（`train.py:82`） | `atr` 取事件发生当根 `ind["atr14"][e.bar_idx]`（`features/build.py:40`），仅依赖 `≤ t` 数据 |

### 2. 训练切分与验证协议源码审计（E1）

| 验证环节 | `chan-model-xgb`（`src/chan_xgb/train.py`） | `chan-quant`（`scripts/train_wf.py` & `backtest/portfolio.py`） |
|---|---|---|
| **多标的合并顺序** | 按币种循环依次追加，未按时间戳重排（`train.py:563-578`） | 全部股票事件合并后执行 `df.sort_values("t").reset_index(drop=True)`（`train_wf.py:36`） |
| **特征标准化时点** | 切分前对全量 `X` 算均值与标准差 `fe.compute_norm_stats(X)`（`train.py:585-588`） | 不做标准化；仅基于子训练集 `ptr` 过滤单值死列 `X.iloc[ptr][c].nunique() > 1`（`train_wf.py:60`） |
| **Walk-Forward 切分** | `walk_forward_split` 忽略 `timestamps`，按行索引 `0 .. n` 切 5 折并留 `purge_gap=20`（`train.py:211-244`） | 按日历月滚动，训练集 `df["t"] <= m.start_time - Timedelta(days=28)`，测试集为当月 `[start, nxt)`（`train_wf.py:39-48`） |
| **Early Stopping 验证集** | 在未按时间排序的折内 `val_idx` 上早停并做 Optuna 50 轮调参（`train.py:276-306`） | 截取每个训练窗口时间最末 15%（`vsplit = int(len(pos_all) * 0.85)`）作为独立验证集早停（`train_wf.py:56-61`） |
| **OOS 评估真实性** | `final_model` 在**全量 `X_norm`** 上训练（`train.py:336-341`），随后用该模型跑 `_evaluate_time_split`（`train.py:600`），测试集实为样本内数据 | 每月模型仅预测尚未见过的当月测试集 `te_pos`，汇总全部月份的真实样本外（OOF）预测后再算 AUC 与分位收益（`train_wf.py:65-72, 91-125`） |
| **组合级回测终审** | 无组合回测，仅输出分类指标 AUPRC / AUC-ROC | `backtest/portfolio.py:33-118` 按时间轴逐 bar 盯市，施加单笔 10% 仓位、最多 10 仓、13bp 成本与盘中止损约束 |

### 3. 不同标签定义下的实证表现对比（E2，作者报告/台账自报，待本仓复算）

以下结论整理自 `chan-quant` 的 `reports/feature_label_catalog.md`、`reports/retro_20261103.md` 及本仓 chan-quant 仓库卡（按 D004/D009 归为 **E2 作者自报结论**）：

1. **直接预测方向收益（`pol_dir_ret > 0`）：持续阴性**：
   - 在月度 Walk-Forward 下，无论是全样本（WF-1，买点 AUC `0.487`）、仅买点（WF-2，AUC `0.487`）还是确认买点（WF-3，AUC `0.502`），模型对单笔交易“是否赚钱”几乎无判别力（`feature_label_catalog.md:187-194`）。
2. **预测大幅波动/尾部命中（`c_pol_dir_ret > 2%` 或 `pol144_ret > +30%`）：存在单调分位分离**：
   - 将标签换为确认买点“是否出现 `>2%` 大波”（WF-4）后，OOF AUC 升至 **0.575**（其中二买 `T2` 子集达 **0.605**，`feature_label_catalog.md:193`）。
   - 若将标签设为 `pol144_ret > +30%`（144bar/3ATR 下的极端右尾，基率 `1.87%`），`pa_atr_pct` 五分位尾部命中率从 `0.69%` 单调升至 `3.76%`（`×5.4` 倍），`pa_dist_hh20` 从 `0.58%` 升至 `3.18%`（`×5.5` 倍，`retro_20261103.md:57-67`）。
3. **预测缠论结构存活（`survive_144` / `clear_bar`）：唯一跨市场稳定阳性标签**：
   - 预测“该 BSP 所在笔是否不会被后续未确认段重算抹除”，OOF AUC 在买侧达 **0.658**、卖侧达 **0.689**，67 个测试月中 100% 月份 AUC $\ge 0.55$，且随样本量从 500 增至 41,000 单调爬升（`0.60 → 0.695`，`retro_20261103.md:33-36`）。
   - **但“结构存活 $\ne$ 交易盈利”**：由于收益呈极端右偏彩票分布（top 5% 交易贡献 357% 净利润，中位交易 `-242bp`），高存活率只代表缠论几何形态稳定，不能直接转化为组合级超额收益（`retro_20261103.md:24-35`）。

## 反例与边界

- **不可引用 `chan-model-xgb` 的高 AUPRC 指标**：由于 `chan-model-xgb` 的 `_evaluate_time_split` 与 `_train_ensemble_tf` 均在全量数据训练后的模型上评估，且打标未计入先触止损的失败路径，其 README 所报 AUPRC `0.944`、泛化差距 `0.011` 属于样本内泄漏伪影（见 chan-model-xgb 仓库卡）。
- **确认入场的样本折损与延迟代价**：`chan-quant` 的 `confirmation_entry` 虽将单笔期望从裸 BSP 的 `-6.0bp` 提升至确认买点的 `+42.6bp`（144bar/3ATR，E2），但覆盖率仅约 `18%`（47,307 个 BSP 中仅 8,646 个确认买点），且入场价相比 BSP 锚定极值点已滞后 `delay_bars + wait_bars` 根 K 线。
- **事件级阳性不代表组合级有效**：由于同一市场行情下多只股票会同时触发确认买点，而组合回测受 `max_pos = 10` 仓位上限约束，高分信号在时间轴上高度聚集时会被大量跳过（`retro_20261103.md:41`）。
