# 专题：缠论机器学习特征工程对比与消融实证

> 更新：2026-11-07 · 状态：草稿

## 问题

在基于 `chan.py` 买卖点（BSP）触发事件的机器学习建模中，`chan-quant`（202 列）与 `chan-model-xgb`（61 列）如何将 K 线序列、技术指标、缠论几何结构与动力学背驰编码为特征向量 $X$？两套工程在特征口径、因果性保障与线上契约上存在哪些实质差异？哪些特征簇在样本外真正贡献判别力，哪些属于冗余或退化死列？

- **研究边界**：本专题仅覆盖模型输入特征矩阵 $X$（共 263 列），不含标签列（`quant` 32 列收益/策略标签、`xgb` 二元标签）与事件元信息列（25 列）。
- **交互式图解**：全部 263 个特征的微距几何解剖图、源码公式、90 根 K 线全局定位与消融矩阵见 [ML可视化.html](assets/ML可视化.html)。
- **逐列清单**：两项目完整特征名与分组对照见 特征清单_xgb_vs_quant.md。

## 结论（E1）

1. **真实注册维度与 README 宣传不符**：`chan-model-xgb` 源码实际注册 **61 列**（`bsp_meta` 12 + `tech` 28 + `chan` 21），其 README 表格写为 63 维、`features.py` 文档字符串写为 56 维均已过时；`chan-quant` 当前源码默认产出 **202 列**（v8），其 README 顶部仍停留在 v6 的 188 列，而 `feature_label_catalog.md` 中的“188 列”实指 v1 数据集 `131 特征 + 32 标签 + 25 元信息` 的总列数。
2. **同名或对应特征存在四类口径分歧**：
   - **归一化分母不同**：`xgb` 的均线偏离 `ma_20_dist = (C - MA20) / C` 与中枢宽度 `zs_width_norm = (ZG - ZD) / C` 均以当前收盘价 `C` 为分母；`quant` 的 `pa_price_vs_ma20 = C / MA20 - 1` 以 `MA20` 为分母，`ch_zs_width = (ZG - ZD) / ZD` 以中枢下沿 `ZD` 为分母。
   - **量纲是否价格无关**：`xgb` 的 `macd_value / macd_signal / macd_hist` 与 `seg_amp` 存储未除以股价的绝对原值，依赖外部 `norm_stats.json` 做 Z-Score 标准化；`quant` 的 `pa_macd_dif / dea / bar` 全部除以收盘价 `C[t]`，树模型直接输入原值。
   - **状态量 vs 事件量**：`xgb` 的 `macd_cross` 只要 `DIF > DEA` 即恒取 `+1.0`（状态量）；`quant` 的 `pa_macd_cross` 仅在当根 bar 刚发生上穿/下穿时取 `±1.0`（事件量）。
   - **同名异义陷阱**：`xgb` 的 `bi_slope = (end_val - begin_val) / begin_val` 实为当前笔带符号涨跌幅；`quant` 的 `ch_bi_slope = bi.amp() / bi.get_klu_cnt()` 才是每根原始 K 线的平均推进速率。
3. **因果性与数据泄漏差异显著**：
   - `chan-model-xgb` 的 `compute_norm_stats(X)` 在切分训练/测试集前对**全量样本矩阵 $X$** 计算均值和标准差，造成测试期分布信息泄漏；其 2 列多级别特征（`higher_tf_trend`、`multi_tf_agreement`）并未读取高级别 K 线，而是直接由本级别 `ma_cross_5_20` 与 `seg_is_up` 推导（伪多级别）；其 5m 模型的 4 列区间套特征（`nesting_*`）因下载脚本未拉取 1m 数据，训练时静默回退为全 0。
   - `chan-quant` 通过 `shift(1)` 构造前 20/50 根高低箱体（`hh20/ll20/hh50/ll50` 不含当前 bar），日线背景 `bg_d_*` 严格只取第 $k-1$ 个已完成交易日广播至第 $k$ 日 30m 序列，动力学出笔 `out_bi` 采用 `is_reverse=True` 截断至笔极值 K 线；除回放后追加的 `mkt_` 8 列外，其余特征受 `test_prefix_invariance.py` 截断重放检验约束。
4. **结构特征存在恒定退化死列**：在 BSP 首次触发时点上，由于缠论笔方向严格交替，`ch_bi_dir_streak` 恒等于 `1.0`；由于最新线段尚未被未来反向线段确认，`ch_seg_sure` 恒等于 `0.0`；默认配置下不生成单笔中枢，`ch_zs_is_one_bi` 恒等于 `0.0`。

### 3. 上游特征体检与消融结论汇总（E2，作者报告自报，待本仓独立复算）

以下数据摘自 `vendor/02_缠论机器学习/chan-quant/reports/feature_effectiveness.md`（按本仓 D004/D009 规则列为 **E2 作者自报结论**，已在 [ML可视化.html](assets/ML可视化.html) 的「🧪 特征体检与消融实证」视图中结构化展示）：

1. **分组消融（131 列口径，3,031 确认买点，预测大波 `>2%` 基线 AUC `0.6027`）**：
   - 移除 `pa_`（价格行为 54 列）：AUC 降至 **0.5567**（**-0.0460**），是唯一具有显著边际正贡献的特征组。
   - 移除 `mkt_`（市场环境 8 列）：AUC 为 **0.5963**（**-0.0064**）。
   - 移除 `pt_`（形态 15 列）或 `ch_`（缠论结构 54 列）：AUC 分别升至 **0.6064**（**+0.0037**）与 **0.6079**（**+0.0052**）。作者解释为：样本已由 BSP 触发条件筛选，再用同源的 BSP 几何结构预测其自身收益无增量信息。
   - 后续扩展复核：v3 新增 Brooks 23 列在 6,169 个确认买点上大波 AUC 增量为 **-0.0043**（`0.5692` vs 去 Brooks `0.5735`）；v8 新增 `bg_` 14 列在 WF#7 上 AUC 为 `0.5084` vs `0.5073`（零增量）。
2. **「强信号」反向陷阱（30m 买点正收益 AUC 显著 `< 0.5`）**：
   - `pa_bar_range_atr`（AUC **0.372**）、`pa_body_ratio`（**0.397**）、`pa_range_expansion`（**0.399**）、`pa_vol_on_break`（**0.404**）、`pa_ft_strength`（**0.406**）、`pa_vol_ratio20`（**0.407**）。在 30m 下跌笔末端出现的放量大阳线或大幅突破往往对应恐慌反抽或短线衰竭，追高胜率反而低于均值。
3. **冗余剔除与 25 列核心集（131 → 25 列）**：
   - 131 列中含 **3 列死列**（`std=0`）、**46 列高共线冗余列**（`|Spearman| >= 0.8`）、**52 列零分裂增益列**（`gain=0`）。
   - 仅保留 25 列核心集（位置/结构 8 列、趋势/通道 4 列、波动/区间 4 列、量能 2 列、结构长度 3 列、买卖点 4 列）重训后，正收益 AUC 从 `0.5220` 升至 **0.5258**，大波 AUC 从 `0.6059` 升至 **0.6142**。

## 反例与边界

- **样本选择偏倚**：`chan-quant` 的消融结论建立在「HS300 成分股 30m 级别、仅限 `is_buy == 1 且 conf_ok == 1` 的确认买点」子集上，不能直接外推到未确认裸 BSP、卖点或日线/5m 周期。
- **方向预测 vs 波动预测混淆**：单变量 AUC 最高的 `pa_atr_pct`（大波 AUC `0.592`）、`pa_range_width20`（`0.575`）本质预测的是未来波幅大小而非涨跌方向（其正收益 AUC 仅约 `0.51`），只适合做仓位缩放或止损宽窄调节，不能单独做多空方向过滤。
- **跨库不可直接比 AUC**：`chan-model-xgb` 与 `chan-quant` 的标的池、K 线周期、打标窗口（`xgb` 用未来 3–24 根是否触及 `1.5×ATR` vs `quant` 用 24/144 根固定持仓与策略止损）及成本假设均不同，未对齐评估协议前不可横向比较模型指标。
