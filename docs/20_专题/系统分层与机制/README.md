# 系统分层与机制台账

> 目的：把 chan-quant 的决策链拆成正交的层，标出每层是「机制 / 默认值 / 已判死 / 未验证」，并把每个判断锚到实验编号与可复算产物。
>
> 证据等级：层内数字全部来自 [实验台账](../../../reports/experiment_log.md) 的 E1 行；「机制 vs 因子」的分类是组织框架，不是新增证据（属 E3 解释）。任何层内改动仍需预注册。

## 0. 一句话结论

七层里只有三层真正有机制：**时间（frenzy 门控）、出场（固定窗口）、研究协议（预注册/审计）**。其余四层——标的池、仓位、成本执行、风险预算——要么是默认值，要么是空白。

而所有「看起来像机制」的候选（breadth、存活过滤、模型筛选、TTR、自适应退出、Brooks 背景、BTC 形态）全部死在同一条线上：**事件级有信号，组合级没增量**。

## 1. 判定标准：什么才算「机制」

一个东西配叫机制，不看叙事多顺，只看四条：

1. **组合级 OOS 同号**，不是事件级（#18/#22/#33 的反面教材）。
2. **参数平台，不是尖峰**（#47 核心区 12 格全正、中位 0.93；#49 hold=48 是 6/6 全正的整行）。
3. **跨切分/跨年不翻符号**（#20 三个自然年门控均胜）。
4. **关错机的代价可度量、可承受**；且「不用调」本身就是特征（#47：IS–OOS 秩相关 −0.305，禁止用 IS 调参）。

反例：事件级单调、组合级恶化 = 不是机制，是暴露密度被削（#18 跳过 484 笔 E=+75.1bp；#33 铁律）。

## 3. 每层细账

### L1 时间层（唯一被验证的机制）

- **机制定义**：日频状态量 → IS 期冻结阈值 → PIT shift(1) → 决定「这一类交易今天允不允许存在」。不回答「买哪个」，只回答「开不开机」。
- **有效证据**：
  - #11 首次发现：A股涨停近邻占比 ≥ 中位时 E=85.5bp vs <p75 39.7bp。
  - #19 真 OOS：门控 +79.5%/夏普 1.21/MDD −12.3% vs 基线 +50.5%/0.80/−21.2%，开机率 40%。
  - #20 稳健性：三个自然年门控均胜；去 top1% 后门控 +106bp（基线 +11bp）。
  - #35 架构对照：frenzy 门控本身就是 regime 切换的最优形态；冷时段替代打法全部证伪。
  - #47 参数面：28 格中 26 格 OOS 为正；核心区 12 格 0.56–1.25、中位 0.93；IS–OOS 负相关，**不许调参**。
- **同层已判死**：mkt_* 单特征门控（#10）、滚动相对阈值（#19 对照）、breadth（#35/#36/#48）、regime 退出（#21）、模型互斥分工（#50）。
- **复现注意**：A股侧复跑依赖 events_v7 与全量 30m 数据，当前门控模块侧待接入；历史数字以台账为准。

### L2 标的池层（默认值，但藏着一个前提）

- **现状**：crypto 10/31 币、A股 289/300 只，人工圈定；没有流动性、上市时长、交易所、稳定币对的筛选机制。
- **隐含前提**：frenzy 是横截面指标，**必须先有足够宽的宇宙**才能定义；单资产无法检验（#25）。所以「宇宙宽度」本身是时间门控生效的前提，但它不是被单独验证过的机制。
- **未验证的坑**：幸存者偏差（只留下活到今天的币）、上市时间偏差、交易所/合约差异。当前所有 crypto OOS 结果都建立在这个未审计的宇宙上。
- **可证伪问题**：把已下架/退市标的补回宇宙，重跑 #19 的 crypto 平行版，看开机率与 E 是否变化。

### L3 信号层（规则，不是机制）

- **现状**：BSP 五类买点全做，不精选。这不是懒，是 #33 的结论：任何窗口内选股都杀死组合，利润=狂热窗口内的暴露密度。
- **关键结论**：信号本身不是 edge 来源。裸 BSP 买点 −6.0bp（#1）；A股 edge 不来自缠论结构，来自狂潮 regime（#25）；换成自定义摆动点，仍是「概率可学（0.61）、赔率不可学（反序）」（#30）。
- **已判死**：短持有期 <96bar（#5）、移动止盈（#5）、方向标签（#3）、大波标签做 144bar 排序（#4）、Brooks 背景过滤（#23/#24）、TTR fade（#32/#35/#45）、BTC 六种 5m 形态（#39–#43）。

### L4 仓位层（默认值）

- **现状**：净值 10% × 最多 10 只；没有波动率目标、没有分数 Kelly、没有 regime 相关仓位。
- **证据**：#36 全仓复利≈7×Kelly，回撤 −83.6%，缩仓只减波动不创造期望；#18/#33 说明降暴露密度会直接砍掉利润。
- **结论**：仓位层只能改**路径**（波动/回撤），不能造**期望**。任何「按分数/按存活定仓位」的提议，必须先过 #33 的暴露密度检验。

### L5 出场层（机制=不动）

- **现状**：固定 48bar/2ATR（crypto）、144bar/3ATR（A股），无止盈、无信号离场。
- **证据**：#21 结构失效退出 E=−9.3bp、regime 退出 +14.0bp、固定 144bar +45.3bp 全胜；移动止盈负优化（#5）；TP5 一致大败（台账 #47「止盈配对」行）；#49 证明 48/2.0 落在唯一稳定平台中部。
- **结论**：固定持有不是「懒得调」，而是等待尾部的物理窗口；这层的正确机制就是「不要动」。

### L6 成本 / 执行层（约束，不是参数）

- **现状**：A股 13bp；crypto taker 12bp 往返（#25）或 10bp 单边（#45），两处口径不同，引用时注明；资金费率、滑点、容量未建模。
- **证据**：#29/#43 证明 5m + 12bp taker 是结构性不可交易；#35 的 13bp 成本杀死 A股区间 scalp；#45 显示加密 TTR 里成本只占 ATR 20%，但信号本身零信息——**成本过了也不代表有 edge**；#37 修正了做空成本符号。
- **结论**：这层是机制级约束，不是能「优化」的参数；未建模的 funding 可能是 bp 级 edge 的隐藏杀手（perp 多头 48h）。

### L7 风险预算层（空白）

- **现状**：只有单笔 stop；没有相关性上限、组合回撤闸、重叠持仓净额。
- **证据**：#9 四个狂潮月贡献 81% 盈亏；#36 组合 MDD −83.6%；#18/#22/#24/#33 反复出现「事件级与组合级背离」；#45/#50 的脚本明确标注重叠持仓未做资金曲线。
- **结论**：这是目前最空的层。先做测量（相关性、重叠持仓、真实组合回撤），再谈机制；不要先加规则。

### L0 研究协议层（已建立）

- **内容**：跑前写预注册（假设/判据/停止条件），跑后不改；IS/OOS 固定切分；安慰剂对照；口径审计；多重检验折减。
- **证据**：#37 修尺后 BTC 卖侧符号翻转、结论作废；#44 审计报告口径与泄漏签名；E001–E004 的参数扫描预注册；#47 明确「禁止用 IS 调参」。
- **结论**：这是七层之外的第 0 层，也是唯一让「机制」标签可信的原因。

## 4. 机制墓地（候选机制与死因）

| 候选 | 看起来像什么机制 | 死在哪 | 编号 |
|---|---|---|---|
| breadth 参与面门控 | 时间层第二维 | OOS 夏普 0.17；在 frenzy 之上反向减分 | #35 / #36 / #48 |
| 存活分数过滤 | 信号质量开关 | 事件级单调，组合级单调恶化 | #18 / #22 |
| 尾部标签 ML | 中奖概率排序 | 组合级第四次死亡；固定 % 标签有波动率伪影 | #33 / #34 |
| Brooks 背景过滤 | 个股状态开关 | 事件级可见，组合/日线级符号翻转 | #23 / #24 |
| TTR fade | 区间战术 | A股被 13bp 成本杀死；加密信号≈安慰剂 | #32 / #35 / #45 |
| 自适应退出 | 出场机制 | 固定持有全胜；regime 退出砍赔率 | #21 |
| BTC 5m 六形态 | 执行级 alpha | 12bp taker 成本墙 | #29 / #39–#43 |
| 模型互斥分工 | 分层协作 | 关机期不单调，开机期相关反号 | #50 |

共同死因只有一句：**把「能预测」当成「能赚钱」**。可预测的是结构存活（#17/#27/#38），可赚钱的是 regime 内的尾部暴露（#19）。

## 5. 下一步（只列可证伪问题，不承诺）

按「地基优先」排序：

1. **L2 幸存者偏差审计**：补回已下架标的，重跑 crypto 开门率与 E。这是所有 crypto 结果的地基。
2. **L6 资金费率 / 滑点建模**：perp 多头 48h，funding 可能吃掉 bp 级 edge；先量化，再谈策略。
3. **L7 风险测量**：相关性、重叠持仓、真实组合回撤。只测量，不加规则。
4. **L4 仓位**：只有 1–3 通过后才值得试；且只能改路径，不能造期望。

**不做**：继续给 frenzy 加参数/加门控（#47/#36）；用模型筛交易（#18/#22/#33/#50）；在 5m + taker 上找形态（#43）。

### 5.1 边界澄清（2026-11-09，D022，原文不删）

上面这条「不做」**继续有效**，但按 D022 明确适用范围：它约束的是「给 frenzy 加参数 / 叠加第二道门控」（#47/#36）和「用模型筛单笔交易」（#18/#22/#33/#50）。

E005 不在该范围内，因为它把**单变量阈值替换成多变量日级判别器**：输出仍是每日一个 0/1，不筛事件、不叠加第二道门控、不在 IS 调参（预注册 §1/§4/§8 写死）。#33 恰好认定「选时间」是唯一存活的过滤类型。这是形态替换，不是加料。

授权仅限 E005 那一次实验，且判据不放宽：#10 / #36 / #47 / E001 的四条阴性证据仍是先验，六条判据（含残差增量与安慰剂对照）须同时成立，单次跑完即停。**后续任何时间层改动都要逐条比对三个不变量**（不筛交易、不叠门控、不调参），不满足即回到禁令范围；本段不构成「时间层可以自由加模型」的先例。

### 5.2 E005 训练目标重定向（2026-11-10，D023，原文不删）

用户明确 E005 的目标是「找更优模型或指标**替换** frenzy5」，不是把 frenzy5 当答案。据此训练目标由「预测未来 frenzy5 状态」改为「预测未来市场实现波动率（回归）」；frenzy5 降为被挑战的 A/B 基线，不再作标签、标准答案或主链路特征。§5.1 的「含残差增量」自 2026-11-10 起按 D023 理解为「对当期已实现波动率取残差、拦住 persistence」，判据不放宽，另加预测层准入门槛（须同时优于 persistence 与 HAR-RV）。

三个不变量不变：输出仍是每日 0/1、不筛事件、不叠门控、不在 IS 调参，故 D022 的范围限定继续有效；本段不新增授权，实现阶段仍须用户另行指令，也不构成「时间层可以自由加模型」的先例。

### 5.4 训练粒度重定向（2026-11-10，D029，原文不删）

用户指定 E006 要「跨标的跨周期泛化、先用 1h 训练、1bar1 行」，并明确「横截面或者其他可以模型训练好后聚合数据，这是具体数据使用」。据此：

- E006 的样本单位改为**一个 `(bar_time, ticker)` 一行**，标签是该标的自身未来 H 根 bar 的 RV；不再在训练里做日级化或横截面聚合。跨标的靠「禁一切标的身份与横截面特征 + 固定留出标的组验证」保证，跨周期靠协议参数化保证（权重仍绑定实例）。
- **横截面聚合从训练侧移到下游数据使用侧**：E005 自行把逐标的逐 bar 预测归约为一条日频市场分数，归约规则作为第三个 IS 冻结项写入自己的产物；`VolForecastGate` 仍只读那份日频分数文件，不碰 bar 级数据、不碰 1h bar。
