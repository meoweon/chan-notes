## 1. 问题与语义边界

现有 L1 时间门控是**单变量阈值**：frenzy5 = 日收盘宽表中单日涨幅 > 0.08 的标的占比、5 日平滑（`chan_quant/gates/frenzy.py:12-17`），经 IS 中位数冻结（`base.py:55-65`）与 PIT `shift(1)`（`base.py:81-90`）决定「今天开不开机」（#19）。

问题：能否用 [E006](E006-跨周期波动率预测模型__作废-20261110.md) 产出的**波动率预测分数**（取相对排序）**替换** frenzy5 成为唯一的 L1 门控指标，在真 OOS 组合级指标上严格更优？

**本实验是下游应用，不是模型训练**：模型怎么训、标签怎么定、协议怎么冻结、预测层如何判准，全部在 E006（D028）。按 D029，E006 的预测是**逐标的逐 bar** 的，本实验先把它归约成一条日频市场分数，再变成日级 0/1，与单 frenzy 门控做组合 A/B。用户 2026-11-10 明确「具体怎么用后续做实验来验证效果，在此之前先不定死」「横截面或者其他可以模型训练好后聚合数据，这是具体数据使用」，故本实验与「像原作者一样管理仓位」是**并列候选**，不是模型的既定归宿；聚合规则也只属于本实验，不构成 E006 的训练口径。

硬边界：

- 输出单位是**交易日**，不筛交易、不做选股（#33 铁律）。
- **frenzy5 不是标签、不是标准答案、不进主链路特征**，只是被挑战的 A/B 基线与一组诊断消融（D023）。
- 「更优」只认组合级指标；QLIKE / log-MSE / OOS R² 属 E006 的预测层判据，**不是本实验判据**。
- 不得把「E006 过了预测层准入」写成「已证明门控更优」。
- 不用当下成分回填历史；特征宇宙与事件宇宙的差异写进结论局限（由 E006 点验冻结）。

## 4. 门控化协议（IS 内冻结，OOS 不动）

- **聚合规则（D029 新增，第三个冻结项）**：两步归约函数与有效币数下限在 IS 内一次冻结、写入 json，与方向、阈值并列。不得用 OOS 选归约方式，不得看 A/B 结果回头换聚合口径（#47）。若多个候选归约都合理，**跑前预注册为并列诊断、不许择优**，或另开实验。
- **方向**在 IS 内冻结（高 ON / 低 ON / 中段区间，写入 json；IS 内无稳定单调关系即停）。#11「Q4 极端狂热反而降温」提示方向可能非单调，故不预设「高波动 ON」。
- **阈值**按 p_on=0.5 用 `freeze_threshold` 冻结（与 #19/#36 基线同开机率）；Q75 仅作诊断分档、不作门控阈值。分数文件输出已定向值，使 `binarize` 的 `>= thr` 语义恒定。
- `binarize`（`>= thr` 为开、NaN 一律关）→ 一列日级 **0/1**；`filter_events` 用 `shift(1)` 把事件日映射到前一天的开关，这是**唯一**的时点映射处。
- 禁止用 OOS 选特征、调阈值、早停或挑超参（#47；E001/E002 显示 IS 最优到 OOS 落到第 182/480）。
- 种子稳定性作为门槛沿用 E006：若 E006 报告种子间分数排序不稳定，冻结阈值不成立，判阴性。

## 6. 判据（七条同时成立）

**前置（非判据）**：E006 产物通过 §0.6 的可用性校验。

**门控成功需七条同时成立（较 D023 版加严一条）**：

1. OOS 组合夏普 ≥ 同口径**单 frenzy 基线** + 0.2，收益与 E/笔不低于基线，OOS 交易数 ≥ 30；
2. 三个自然年 OOS 逐年同号（#20）；
3. 去 top1% 交易后 E 仍为正（#20）；
4. 安慰剂（标签时间错位 / 打乱）无增量；
5. **去 persistence 增量**：分数对「当期已实现波动率」取残差，仅用残差做门控仍满足第 1 条；
6. **去 HAR 增量**：分数对 HAR-RV 取残差后仍有组合级增量，否则判为「ML 只是重发现 HAR」（外部参照 LightGBM 重要性前两名即 22 日 GK 与 log-RV 滞后）；
7. 开机率 20%~60%，且与基线同 p_on=0.5 冻结口径；种子间分数排序稳定（§4）。

失败：任一条不满足即阴性。**诊断项（不参与择优但必须报告）**：与 frenzy 开机日的 Jaccard 重合度（>0.9 且组合指标无差异 → 判「换皮不替换」）、换手与成本敏感性、`+frenzy5` 消融。特征重要性与四组消融报告归 E006。

> 预测层准入门槛（QLIKE 与 log 空间 MSE 同时优于 persistence 与 HAR-RV、DM 口径、OOS R²、种子敏感性）已按 D028 迁入 [E006 §5](E006-跨周期波动率预测模型__作废-20261110.md)，不再是本实验的阶段或判据。

## 7. 假设（跑前写死）

- H1（主）：E006 的波动率分数经 IS 冻结方向与阈值后，OOS 组合夏普 > 单 frenzy 基线 + 0.2。
- H2：分数相对当期 RV 的残差仍有组合级增量（不是 persistence 的复制品）。
- H3（预期反例）：按 #10/#36/#47/E001 先验，预测层能打赢线性基线但门控层不优于 frenzy；结果由开机日与狂潮月的重合度主导（#9：四个狂潮月贡献 81% 盈亏）。H6（预测层赢不等于组合层赢）的实质已并入本条与 §9。
- H4：标签错位后预测与门控均无增量；若有，判口径泄漏、实验作废重查。
- H5：开机日与 frenzy 高度重合且组合指标无差异 → 判「换皮不替换」，阴性。

## 9. 已知风险（跑前登记，不是事后解释）

- **过拟合仍是先验主结果**：E006 逐 (bar, ticker) 样本为百万行量级，但标签重叠 95.8%、有效独立「波动波次」仍有限；禁用标的身份特征后无法按币校准波动中枢，IS→OOS 映射更易失效（详见 [E006 §8](E006-跨周期波动率预测模型__作废-20261110.md)）。本实验又多一层聚合自由度：归约方式若不在 IS 冻结，等于新增一组可选参数，须防 #47 式选优。
- 四条阴性证据：#10 市场特征四分位门控无单调分离（`experiment_log.md:43`）；#36 breadth 叠加后夏普 0.99→0.64 且条件信息方向相反；#47 IS–OOS 秩相关 −0.305；E001 IS 最优组合 OOS 夏普 −0.389。「Q75 高波动 ON」本质就是 #10 换个特征源，#11「Q4 极端狂热反而降温」提示方向非单调，故方向在 IS 冻结、无单调即停。
- **预测能力 ≠ 交易价值**：外部参照的择时扩展里 LSTM 相对 HAR 的样本外 R² 有两位数百分比提升，扣成本后净 Sharpe 几乎没有改善，点预测最差的 GARCH 净 Sharpe 与 LSTM 相当而换手远低（外部参照的结论）；Branco / Rubesam / Zevallos（2024, *Journal of Empirical Finance* 78:101524）第三条结论为「月度 RV 预测构建的波动率择时组合，经济价值上不带额外预测变量的简单 HAR 类模型反而更好」，且所有模型在高波动期倾向低估 RV —— **最需要识别的高波动 regime 恰是系统性低估的区间**，对「高波动 ON」是直接负面证据。#33 铁律（事件级阳性在组合层已死四次）仍适用。第三方论文结论为 **E2**，只作先验不作本仓结论。
- 外部参照五处已知缺陷（幸存者偏差、DM 口径错配、holdout 漂移、产物链不完整、无预注册）的规避、无美股预演的风险、币池成分漂移、标签平稳性、qlib 日历不一致，全部由 [E006](E006-跨周期波动率预测模型__作废-20261110.md) §3 / §5 / §8 承担；本实验只读其冻结产物。
- 外部参照 README 的绩效数字、GK 效率高 7–8 倍、SHAP 解读均为 **E2**，本仓未复算，不采信为结论；GK 标签若要评估须另开实验，不在本实验内换标签。
